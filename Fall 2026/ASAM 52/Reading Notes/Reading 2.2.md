## 关键定义（务必记牢）

| 术语                                                | 定义                                                                                                                                             |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **成就悖论（achievement paradox）**                     | 亚裔移民子女的教育成就**超出**其家庭社经地位（SES）与主流文化资本所预测的水平；但同一批人在职场上却**得不到**与白人同等教育者相当的管理职位与回报。                                                                |
| **成功框架（success frame）**                           | 移民父母传入的、关于"成功"的**严格定义与唯一路径**：全 A → 高中毕业生致辞代表 → 进入名校 → 取得高等学位 → 从事"四大职业"（医、法、工程、科学／或药剂）。**不是亚裔天生固有，而是被超高选择性移民建构并推崇的。**                          |
| **框架（frame，Goffman 1974）**                        | 我们观察、诠释、分析社会生活的**透镜**；不是文化固有，也不直接导致行为，而是通过划定"可能性地平线"（horizons of possibilities）使某些行为变得可能或更可能。                                                  |
| **族群资本（ethnic capital，Borjas 1992）**              | 一个移民群体内部的**群体层面社经资源**（尤其受过大学教育的同族比例）；高族群资本创造并供给族群资源，使低社经地位的父母也能让子女向上流动。                                                                        |
| **族群资源（ethnic resources）**                        | 族群资本的具体形态：族群经济中的工作与自雇机会；课后补习班、SAT 冲刺班、升学资讯；以及**流动原型（mobility prototypes）**——可见的高成就同族榜样。                                                        |
| **地位获得模型（status attainment model）**               | Blau & Duncan（1967）：父辈职业／教育是子辈教育成就**最强的预测项**。本章的靶子：它无法解释低社经地位的亚裔移民子女为何"超额"成功。                                                                  |
| **文化资本模型（cultural capital model）**                | Bourdieu、DiMaggio、Lareau：家庭传递的**非经济资源**（品味、举止、语言、知识）在"门户制度"（学校、职场）中被奖励，从而再生产优势。局限：**忽视家庭之外的情境因素**（族群资本）。                                       |
| **主流文化资本（dominant cultural capital，Carter 2005）** | 支配群体所看重的高地位文化信号与实践（博物馆、古典乐、钢琴小提琴、言语风格）。                                                                                                        |
| **参照群体（reference group）**                         | 亚裔第二代**不与白人、也不与美国平均比较**，而是与**最高成就的同族**（兄弟、表亲、朋友、同侪）比较——因此永远"不够成功"。                                                                             |
| **亚洲尺度／亚洲式 F（Asian scale / "Asian F"）**           | 受访者描述的评分标准：**A 是平均，B 是"亚洲式的失败"**；另一些版本："A 是 average，B 是 bad，C 是 crap，F 是 find another family。"                                                 |
| **正向选择性（positive selectivity，Feliciano 2005）**    | 移民比**原籍国不移民者**受教育程度更高。                                                                                                                         |
| **超高选择性（hyper-selectivity）**                      | **双重正选择**：某群体不仅比原籍国不移民者更可能大学毕业，**还比移居国总体人口**更可能大学毕业（如华裔）。                                                                                      |
| **低选择性（hypo-selectivity）**                        | **双重负选择**：比原籍国不移民者**和**移居国总体人口的教育都更低（如墨西哥移民）。                                                                                                  |
| **文化贫困论 vs. 成功文化论**                               | 二者同时兴起、互为镜像：Oscar Lewis（1965）与 Moynihan（1965）的"文化贫困论"解释黑人与波多黎各人的代际贫困；《美国新闻与世界报道》（1966）的"成功文化论"则把亚裔成就归因于家庭凝聚、勤奋、纪律与延迟满足。**两者都诉诸群体文化价值来解释流动结果。** |
| **刻板印象承诺（stereotype promise，Lee 2014）**           | 被老师、辅导员、同侪**正面看待**为聪明、高成就、勤奋、值得时，表现获得提升的效应——可成为**自我实现的预言**。与 Steele 的**刻板印象威胁（stereotype threat）**相对。                                          |
| **竹子天花板（bamboo ceiling）**                         | 阻碍亚裔晋升高阶管理／领导职位的**隐形结构性障碍**，犹如女性的玻璃天花板。                                                                                                        |
| **大学冒充者（college impostor）**                       | 未被录取却装作在读、或已退学却继续伪装在校的（亚裔）学生；Ninh 研究的是其中最耐人寻味的第三类。                                                                                             |
| **诈骗者／伪演者／伪装者（scammers / shammers / passers）**    | Ninh 的三分：**scammers** 图明确物质利益（假成绩、假文凭）；**shammers** 的欺骗换不来物质利益、也不套用现成社会脚本；**passers** 才是全书要解释的第三类。                                             |
| **为模范少数族裔而伪装（passing for model minority）**        | Ninh 的**悖论式说法（oxymoron）**："他们因**占住了被派定的位置**而越界，因**太努力取悦**而冒犯。"                                                                                 |
| **模范少数族裔作为身份（model minority as identity）**        | 不是"神话"（可被经验证伪），而是一套**信念与抱负**——"不论当下社经地位或未来可实现性"，是一种关于成功的**正统信仰**。试金石：一个亚裔是否**依这些标准感到骄傲或羞耻**。                                                   |
| **常识（common sense，Gramsci）**                      | 某些对现实的感知看似合乎逻辑、不可避免，尽管它们是文化特定的、并服务于掌权者的利益。Ninh 用来说明成功框架如何被亚裔第二代**内化**。                                                                         |
| **类型（genre）／亲密公众／残酷的乐观主义（Berlant）**               | genre＝"情感投入的、模式化的期待集合，关乎如何行动与如何诠释"；它不只组织审美生产，也组织**时间经验**。                                                                                      |
| **掩饰（covering，Yoshino）**                          | *Covering: The Hidden Assault on Our Civil Rights*：不是隐藏身份本身，而是**压低**身份的可见度。                                                                    |
| **白人性作为财产（whiteness as property，Cheryl Harris）**  | "被视为白人"是一种**名誉利益（reputational interest）**，内在地与身份及人格绑缚；模范少数族裔身份享有很多特权——**只是不是白人特权**。                                                            |

## 一、Lee & Zhou（2014）—— 《成功框架与成就悖论》

### 核心论点
**"虎妈"式的文化本质论（Chua）与地位获得／文化资本两大社会学模型，都无法解释亚裔移民子女的"超额"教育成就。** 作者主张：**文化确实重要，但不是以本质主义的方式**；文化通过**框架（frames）** 运作，而框架需要**族群资本与族群资源**的支撑。华裔与越裔第二代即便出身低社经地位家庭，也共享同一个严格的"成功框架"，并被族群资源托举着达成出乎意料的成就。但**这一框架有代价**：达不到其严苛标准者会觉得自己是**族群异类（ethnic outlier）与失败者**，进而**疏远同族与自身族裔认同**——从而**反过来强化了"族裔＝成就"的虚假关联**。

### 理论脉络：从"文化贫困论"到"文化复归"
- **地位获得模型**（Blau & Duncan 1967）：父辈职业是子辈职业最强预测项，优势代际传递。→ 无法解释低社经地位华裔子女与中产同族比肩、甚至超过中产白人。
- **文化资本模型**（Bourdieu 1984；DiMaggio 1982；Lareau 2003；Carter 2005）：解释**为何**SES 重要，但**忽视家庭之外的情境因素**。
- **历史插曲**：Moynihan 报告（1965）以"**病态纠结（tangle of pathology）**"解释黑人贫困，导致**文化解释被政治污名化**，社会学数十年转向纯结构分析。
- **文化复归**（Carter、Harding、Lamont & Lareau、Small、Vaisey、Young）：新一波学者拒斥"文化＝不变的核心价值"的本质主义定义，改以**更窄的分析概念**（文化资本、框架、剧目、叙事、图式、群体边界）来经验检验文化。
- **框架概念的三个用例**：Goffman（1974）的透镜；Small（2004）波士顿拉丁裔住房项目中的"邻里叙事框架"；Young（2010）黑人男性对"好工作"的框架差异影响就业结果。
  > 关键推论：**不是某些族群"更重视教育"，而是他们建构了极为不同的"好教育"与"学业成功"的定义**——取决于何种框架对他们可及、以及他们采纳了哪个框架。

### 族群资本如何运作：三种方式
1. **族群经济中的有形资源**：工作、住房、自雇机会；以及课后补习、补充教育、升学准备课程。
2. **社会网络联结**：低 SES 成员通过族群经济，接入**跨阶级的族群网络**，获取原本遥不可及的**升学资讯**（高中排名、好学区、AP 课程、补习、大学申请流程）——正式渠道（族群报纸、媒体）与informal渠道（亲属、同族朋友圈）并行使资讯**跨越阶级界线**（Lareau & Calarco 的"cross-class learning"；Small 的"unanticipated gains"）。
3. **可见的榜样／流动原型**：高成就同族——而非中产白人——成为**参照群体**，从而**扩展了第二代的机会地平线**，超出地位获得与文化资本模型的预测。

### 数据与方法
- **IIMMLA**（Immigration and Intergenerational Mobility in Metropolitan Los Angeles）：洛杉矶五县 4,800 份随机电话调查；本文用其描述统计。
- **质性部分**：**82 个**面对面的生命史深度访谈，1.5 代与第二代**华裔（41）与越裔（41）**（另有墨西哥人 56 人作对照，及 12 名本土黑人、12 名白人参照）。访谈时长 1.5–2 小时，全程录音、逐字誊录、按题目与主题编码（ATLAS.ti）。
- **选洛杉矶的理由**：62% 居民是移民或其子女。
- **选华裔＋越裔的理由**：**移民历史、社经背景、定居模式差异极大**（华裔移民来源多元、历史最久；越裔多为 1970 年代中后期难民、教育极低），但**第二代教育结果趋同**——这种"**第二代趋同（second-generation convergence）**"正是悖论所在。

### "成功框架"：A 是平均，B 是亚洲式失败
- **高中是义务，大学是责任，只有拿到高等学位才配得上喝彩。**
  > Caroline（35 岁，第二代华裔，电影业）转述母亲对"高中毕业"的态度：
  > "This is a good day, but it's not that special. … It's not necessarily a privilege; it's an obligation. You must go to high school, and you must finish. It's a further obligation that you go to college and get a bachelor's degree. Thereafter, if you get a Ph.D. or a Master's, that's the big thing…"
- **框架的四步骤**：全 A → 毕业生致辞代表／副代表 → 顶尖 UC 或常春藤 → 研究生教育 → **"四大职业"：医生、律师、药剂师、工程师**。
- **"亚洲尺度"**：A 是平均，B 是亚洲式失败（"A is for average, and B is an Asian fail"）。
- **框架的种族化**：受访者不论是否认同，都知道这是"**亚洲人的事（the Asian thing）**"；在硅谷等地的学校，亚裔被定型为高成就、勤奋、成功，白人中产学生反被视为"平庸""还行（just alright）"——**翻转了传统的种族成就等级**（Drake；Jiménez & Horowitz 2013）。
- **最惊人之处是框架的一致性**：**不论父母教育、职业、阶级、移民史**，华裔与越裔受访者都复述同一框架。在洛杉矶市中心**贫民住宅区**长大、父母只有**六年级学历**、在唐人街制衣厂工作、不会英语的 Maryann，照样说出"UCLA、Berkeley、Yale、Harvard、Princeton、Stanford"和"医生或律师"。她的父母虽处劣势，却通过**族群网络中的流动原型**获得资讯——**低父母人力资本没有截断她的机会地平线**。
- 反面：即便 GPA 4.21、高中第三名、获 UCLA 与 Berkeley 录取的 Hannah，被问及是否骄傲时只淡淡回答："**It would have been better if I was first or second.**"

### 支撑框架：族群资源的三个案例
- **Christopher（27 岁，第二代越裔）**：难民父母只有四年级学历；父母在朋友建议下**把法定监护权转给同族友人**，以便他能就读橙县富裕学区的竞争性高中，同时远离越裔帮派。结果：德州大学奥斯汀分校计算机学位，财务分析师，年薪 7 万美元，超过父母收入总和。
- **Jason（25 岁，第二代华裔）**：长滩工人区出生，父母从《**Chinese Yellow Book**》（每年出版的族群商家电话簿，附**地区高中排名与全国最佳大学名单**）得知 Cerritos 高中"排名十几位"，便举家迁往该中产地名社区（ethnoburb）。入学考试被编入普通班后，父母立刻经由族群网络把他送进**每天三小时的华人课后补习班**；高中考试时进入 AP 轨道。最终提前三年从 UCLA 毕业，正在读法学院。
- **Hannah（25 岁，第二代越裔）**：暑假永远在暑期学校与补习班"**超前学习**"："In the Asian community, I think everyone does tutoring." 结果：UCLA 毕业，正在申请药学院；妹妹在药学院，弟弟在医学院。
- **结论**：**补习班同时是中产创建的策略，也是工人阶级同族可负担、可及的资源**；它使工人阶级家庭**跨越自身的阶级劣势**，也**削平了族群内部的阶级差异**。

### 代价一：成就悖论——永远与最高成就的同族比较
- 因为参照群体是**高成就同族**（兄弟姐妹、表亲、朋友、同侪），而非白人、黑人、拉丁裔或美国平均，**不论成就多高都觉得不够**；"总有一个认识的人做得更多"。
- **Carolyn（35 岁，第二代华裔）**：Cal State 电影研究学位，视觉特效统筹，年薪 6 万美元，热爱工作且能自给；但因未进 UC 系统，父母"失望"，没有"**吹嘘权（bragging rights）**"——表哥表姐多毕业于 MIT、Stanford、Cornell 并当医生律师。她形容自己是家里的"**黑羊（black sheep）**"。
- **Sarah（1.5 代华裔）**：拥有获利丰厚的承建与设计公司，去年赚 16.5 万美元，在富裕社区有房——却因**没有高等学位**而"**not yet**"成功；直到被追问，她才第一次想到与同龄白人朋友相比自己其实更成功。
- **Jemmy（1.5 代华裔）**：在实验室做研究、志在博士；未获任何顶尖博士项目录取，因此觉得"只有学士"的自己像**彻底的失败者**（美国不到 1% 人口有博士学位，但他的参照群体里"人人都有或正在读博"）。

### 代价二：把族裔与成就绑在一起（coupling ethnicity and achievement）
- 因为相信成功框架是**族裔文化的产物、也是族裔认同的体现**，达不到或拒绝框架者往往**疏远同族与自身族裔认同**，而不是去挑战框架本身：
  - **Paul（33 岁，第二代华裔）**：自由艺术家，六位数收入，与坚持"医生／律师／科学家"的父亲决裂、多年几乎不往来。他说自己是"**你见过最白的华人（the whitest Chinese guy you'll ever meet）**"，甚至**改掉姓氏拼法**以免客户见面之前察觉其族裔身份；但他也明白："I'm an American at heart, but I'm Chinese, undeniable."——**表型让他无法彻底退出种族身份**。
  - **Andrew（21 岁，第二代越裔）**：觉得"不够越南（not Vietnamese enough）"，因为弟弟在名校读生物、即将进医学院，是"我没能成为的一切"；他偏好**种族标签**"Asian American / American Asian"而非族裔标签。
  - **Lana（25 岁，第二代越裔）**：社区大学毕业后做零工（保姆、照顾老人、偶尔做影视），梦想进电影幕后；她说同族社区以"**三个 M**：Money, Motorola, Mercedes"定义成功，因此尽量不与越裔社区来往，并选择"Asian American"认同。
- **自我选择的意外后果**：**符合框架者更认同并接触族裔社群、更可见**（族群报纸、族群新闻还会特别报道），**不符合者退出、变得不可见**——于是"看似无关紧要的种族／族裔标签选择"**把原本虚假的"族裔＝成就"关联变成了仿佛真实的关联**，使成功框架代代延续。
- **既有研究佐证**：第二代韩裔若未进名校、无高薪专业工作，会因"失败"而不觉得自己"真正的韩国人"（Lee 2006）；东南亚难民子女若学业失败，更易与家庭和族群社区脱钩（Caplan et al. 1989；Zhou & Bankston 1998）。

### 结论：把种族／族裔与成就"解绑"（decoupling）的四个好处
1. **承认大多数亚裔并不"卓越"**，从而不再因不符框架而自认族群异类或失败者。
2. **提升自尊**：Massey et al.（2003）发现亚裔大学生学业成绩最高，**自尊却最低**，也最少自认"好学生"；解绑后可用更合理的标尺衡量自己。
3. **惠及其他群体**：黑人、拉丁裔常被老师与同侪定型为低成就而遭受**刻板印象威胁**；白人学生在亚裔密集地区也被视为"学业上较差"（Jiménez & Horowitz）。
4. **拓宽成功框架**：作者也承认框架的**正面功能**，但主张**放松**它——第二代已开始另辟蹊径，欧洲族裔后代的经历预示这将会持续（Alba & Nee 2003；Foner 2010）。
> 对标 Carter（2005）：黑人、拉丁裔青年并不把学业成就等同于"acting white"；"acting white"指的是**文化风格与品味**（音乐、穿着、食物、言语），而非反成就意识形态。**今天"种族／族裔＝学业成就"的配对已越出黑白二元——亚裔（而非白人）成了学业卓越的样板。**

## 二、Zhou & Lee（2017）—— 《超高选择性与文化的重塑》

### 核心论点
评论家（与 Pew 报告）常把亚裔的教育成就归因于**天生固有的亚洲文化价值**；本文主张：**文化有结构性的根**——即 **1965 年《哈特—塞勒法》** 之后进入美国的**高教育、高技能移民潮**。作者用**超高选择性（hyper-selectivity）**这一概念，说明移民群体的选择性本身如何**重塑文化**，并在**个体家庭与父母社经特征之外**，产生**群体层面的优势（或劣势）**。由是导出：成功框架、族群资本、**刻板印象承诺**，以及——**竹子天花板**。

### 从"文化贫困论／成功文化论"到"文化的结构性根源"
- Pew（2012）《亚裔美国人的崛起》引发亚裔学者与社区领袖批评：Pew **选择性呈现**教育成就与中位家庭收入，又强调亚裔更重视勤奋，从而诱导读者做出**因果推论**——"亚裔的价值观驱动其社经结果"。
- 作者指出：这与 **Chua 的《虎妈战歌》** 以及 David Brooks、Charles Murray 乃至部分学者的论证同构，其实是把"**文化贫困论**"倒转为"**成功文化论**"的同义反面——**两者都以群体文化价值解释流动结果**，而文化贫困论早已被社会科学界抛弃。
- **本文的反命题**：亚裔的成就与文化表现**有深刻的结构根源**，即改变亚裔移民社经构成的 **1965 年移民法**。"亚洲性"中**没有任何本质性的东西**可以解释这种成就。

### 超高选择性／低选择性：定义与数据
- **正向选择性（positive selectivity，Feliciano 2005）**：移民比原籍国不移民者受教育程度更高。
- **超高选择性（hyper-selectivity）**：**双重正选择**——比原籍国不移民者**和**移居国总体人口都更可能大学毕业。
- **低选择性（hypo-selectivity）**：**双重负选择**。

| 群体 | 移民中大学毕业比例 | 原籍国成年人大学毕业比例 | 美国总体 | 判定 |
|---|---|---|---|---|
| **华裔** | 51% | 4%（中国的 12 倍以上） | 28% | **超高选择性** |
| **越裔** | 26% | 5% | 28% | 正向选择（**未达超高**） |
| **墨西哥裔** | 5% | 17% | 28% | **低选择性** |

- **关键洞见**：超高选择性与低选择性使群体成员在向上流动的**起点（starting points）**上截然不同，并各自产生**文化、制度与社会心理**后果。**华裔：** 一个庞大且高教育的中产阶级移民群，从原籍国**选择性输入**中产阶级特有的文化框架、制度与心态，并在移居国**再造**其中最有用的部分。
- **重要限定**：**因美国的种族化过程，亚裔各族群被均质化为"亚裔美国人"这一宽泛种族标签**，使**族裔、阶级、世代、移民史**的差异被抹掉——因此**正向选择（越裔）甚至低选择（苗族）的群体也可能被正面定型**，共享东／亚裔高教育群体的刻板印象。

### 超高选择性的四重后果
1. **严格的成功框架（success frame）**：全 A → 高中毕业生致辞代表 → 名校 → 高等学位 → **四领域：医、法、工程、科学**。**并非亚裔天生固有**，而是被超高选择性亚裔移民族群建构并推广，再因种族均质化而影响其他亚裔次群体。
2. **族群资本的形成**：以同族大学毕业生比例衡量的人力资本越高，越能通过创业等转化为**族群社区资源**。具体形态：**课后补习学院、考试冲刺班、SAT 预备课程**——由族群企业家经营，**价格可负担、对工人阶级家庭可及**，帮助其克服阶级劣势、有效驾驭美国教育体系。
3. **刻板印象与刻板印象承诺**：亚裔被定型为聪明、自律、勤奋、尊敬——这**正面影响**老师给的分数、额外辅导、以及被编入 **GATE、AP、荣誉轨道（honors track）**的机会；学生也为了**不成为那个"证实不了刻板印象的异类"**而努力，于是**自我实现**。（如 Nam，初二成绩平庸却被编入荣誉班，自己都不知道怎么进去的；此后认真起来，GPA 超过 4.0，被所有申请的 UC 录取。）
4. **竹子天花板：刻板印象的双刃剑**。
   - 同等的教育水平下，亚裔收入低于白人（控制专业领域、大学类型、居住地区、出生地后亦然；Sakamoto、Goyette & Kim 2009）；美国出生的亚裔女性收入与白人女性相当，**却更少被提升到管理 supervisory 职位**（Kim & Zhao 2014）。
   - **湾区顶尖科技公司**（Google、HP、Intel、LinkedIn、Yahoo）：亚裔占**专业人员的 27%**，却只占**经理的 19%**、**高管的 14%**；Marilyn Fernandez（1998）显示亚裔工程师即使控制年龄、教育、年资与绩效评估，仍比白人同事更难晋升管理职。
   - **文化再次被用来解释竹子天花板**：亚裔被认为勤奋、恭顺、尊重（好员工），但也被认为**过于规避风险、安静、缺乏创意、缺乏有效沟通与社交技能**（弱领导）。Fiske 等人的研究显示，受访者会把勤奋、认真、安静**重新框定为被动、软弱、冷漠**——而**这一框定只在面对亚裔外群体时发生**。
   - **悖论**：**在学校帮了亚裔的刻板印象，在职场晋级时反噬他们**——这构成有待进一步研究的"亚裔美国人成就悖论"。

### 方法
- **IIMMLA**：洛杉矶都会区 4,800 名 20–40 岁 1.5／第二代随机电话调查（含墨西哥、华裔、越裔、菲裔、韩裔、危地马拉、萨尔瓦多裔，及本土白人与黑人）。
- **质性部分**：**华裔 41、越裔 41、墨西哥裔 56**（另含 12 名本土黑人、12 名白人参照）；受访者 20–42 岁（平均 28 岁），性别与世代大致均衡；访谈于 **2006 秋–2009** 进行。

### 结果：用"起点"与"代际流动"重新定义成功
- **第二代华裔**：教育成就最高（63% 学士以上，其中 22% 研究生；无人高中辍学），但其父母中 61.3% 父亲、42.3% 母亲已具学士以上——**几乎没有代际增益**。
- **第二代墨西哥裔**：教育成就最低，却**代际流动最大**——高中辍学率从父母一代近 60% 降到第二代 14%；学士以上达 17%，是父亲（7%）的两倍多、母亲（5%）的三倍以上。
  > **作者直言**："If we take into account their different starting points, the children of Mexican immigrants are more successful than those of Chinese immigrants."（若考虑不同的起点，墨西哥移民子女比华裔移民子女更成功。）
- **地位获得模型失灵之处**：**父母未高中毕业的华裔子女，取得学士学位的比例反而高于全部华裔子女（71% vs. 63%）**；族群性即便控制所有可测的人口与社会经济变量后仍有效（Portes & Hao 2004；Hsin & Xie 2014；Tran 2016）。作者认为缺失的正是**超高选择性**的作用。
- **政策含义**：因为墨西哥移民及其子女常是移民政策辩论的焦点，**如何呈现其"进步"的数据**会影响美国公众与决策者如何看待全面移民改革与种族不平等的根源。

### 结论三点
1. **成功不能只看结果，必须看起点**：超高选择性群体的子女平均表现更好，是因为**起跑点更有利**；对低选择性群体，**代际流动性**才是更相关的衡量。
2. **社经与人口变量无法解释**为何低父母人力资本对华裔子女的阻碍方式与其他群体不同；**超高选择性**（1965 年移民法之果）**重塑并强化了成功框架**，并为中产与工人阶级同族都创造了支撑该框架的**族群资本**。
3. **超高选择性也影响他人如何看待第二代、以及第二代如何看待自己**，产生包括**刻板印象承诺**在内的社会心理后果；由种族化过程，关于华裔的偏见与刻板印象会**外溢**到其他东亚与更广泛的亚裔群体。**所谓正面刻板印象是双刃剑**：学校帮忙，职场阻碍。

## 三、Ninh（2021）—— 《大学冒充者的奇异案例》（导论）

### 核心论点
**"模范少数族裔"在我的来处不是一个神话。** Ninh 拒绝"神话"这一社会科学式的证伪框架，主张把模范少数族裔理解为一种**身份（identity）**——"一套信念与抱负，不论当下的社经地位或未来的可实现性"。它不是关于收入或 GPA 的统计命题，而是一种关于成功的**正统信仰**："**模范少数族裔就是要'知道'（哪怕同时憎恨它）成功意味着依序打中每一个成就检查点，因为大家都知道。**"

> **全导论的枢纽问题**：一个按成功框架被养育长大的亚裔，**为何会走到"完美伪装（passing for perfect）"这一步**？
> "How do well-behaved Asian Americans become people with no felt options, no thinkable alternatives to the success frame?"

### 开篇两个病例
- **Azia Kim**：一切表象上都是斯坦福新生——住宿舍、在图书馆熬夜、在社交媒体上抱怨期中考。**九个月后**校方与同学才发现：她**从未被录取**。
- **Jennifer Pan**：微积分不及格本意味着要告诉父母她没有高中文凭、失去了大学提前录取；她选择**假装**四年本科加药学院已读，最终被揭穿时，**雇凶杀害父母**。
- 作者坦承：告诉别人这本书写的是"大学冒充者"，通常需要花时间解释"**是的，真有这样一类人**"。她聚焦其中一类：**未被录取、或已退学，却以继续假装的方式回应的那些人**。

### 三种类型：scammers / shammers / passers
- **Scammers（诈骗者）**：图**明确的物质利益**（现金、奖项、名校文凭），包括用假成绩单／推荐信入学、编造姓名与人生经历，或本就有（通常非暴力的）财务犯罪前科（支票伪造、侵占、信用卡欺诈、盗窃）。**数据：14 名非亚裔冒充者中 11 名（78%）属此类；9 名亚裔冒充者中只有 1 名（11%）属此类。**
- **Shammers（伪演者）**：伪造**换不来物质利益**，且不套用现成社会脚本。
- **Passers（伪装者）**：**第三类**，也是全书要解释的对象。
- **规模与比例**：十年内美加媒体报道了至少 **9 名亚裔**、**14 名非亚裔**（白人、黑人、拉丁裔合计）大学冒充者——**比例上亚裔被过度代表**。

### 本书的方法与定位
- **mixed methods, literary deliverables**：Ninh 是文学批评家，强项是**细读文本与故事**，从**例外与离群值（outliers）**中读出真相。故引 Ursula Le Guin《**The Ones Who Walk Away from Omelas**》：整座城市的繁荣幸福，以**一个孩子被囚于地窖**为条件，居民皆知——"**the truth of a thing is in its outliers**"。
- **不是**流行病学式研究（谈不上发生率、分布、决定因素），**不是**真凶揭露（"this is not an exposé"），**不是**以猎奇视角消费私人生活。受访者多拒绝采访、无人写回忆录，作者靠**档案、文化产物（博客评论、讨论串、高中年鉴）与"跑腿式"采访**拼凑——"data gatekeepers"与"interview subjects"的善意是唯一通路。
- **与前作的关系**：*Passing for Perfect* 是 *Ingratitude: The Debt-Bound Daughter in Asian American Literature*（2012）的**"prequel（前传）"**、一次"do-over"沃土。*Ingratitude* 用学术黑话（"academese"）隐藏真话、对亲属讳莫如深；本书**真话照旧、但把打击垫软**。
- **理论资源**：Lauren Berlant 的 **genre／intimate public／cruel optimism**（Ninh 称之为"文化上的圆周率 π"——不该傻到弃用这些现成构造）；Kenji Yoshino 的 **covering**；Judith Butler 的**述行性（performativity）**；Tina Chen 的 *Double Agency: Acts of Impersonation in Asian American Literature and Culture*（"perform[ing] themselves into being as persons recognized by their communities and their country"）。

### "passing … for model minority"：为何用"伪装"一词
- **历史语义**：在美国的种族分层中，passing 意味着**冒充另一个种族群体成员、并因此表演白人性**；这是**在胁迫（duress）下做出的选择**——奴隶制时期、重建与吉姆·克劳时期，passing 是进取举业、进入被白人垄断的职位的**战术**。
- **代价与共谋结构**：它是**群体的沉默共谋（conspiracy of silence）**；法律学者 Cheryl Harris 的祖母在百货公司当"假定为白人"的店员——"**Day in and day out, she made herself invisible, then visible again, for a price too inconsequential to do more than barely sustain her family and at a cost too precious to conceive.**"史家 Allyson Hobbs（*A Chosen Exile*）："To pass as white meant to lose a sense of embeddedness in a community or a collectivity… identity is found, not in an individual's qualities, but rather in the ways that one recognizes oneself and is recognized as kindred."
- **述行性命题**：**passing 挑战了本质主义**——"**race not as what you are but how you do you**"；"to be white in America is not (biological) fact but (cultural) act—as it is, likewise, to be Black, Asian, etc."
- **paradox／oxymoron**：亚裔冒充者被说成在"**为模范少数族裔而伪装（passing for model minority）**"，这本身是个**矛盾修辞**——因为模范少数族裔正是他们**被派定的位置**，他们却因"占住这个位置"而**越界**、因"太努力取悦"而**冒犯**。它捕捉到：**想达标，却永远无法真正达标**。
- **"passing"不等于"想变白（wannabe white）"**：亚裔模范少数族裔的志向**不是成为白人，而是胜过白人**。成功框架的核心由**尖锐的种族差异感**铸成：为何非要高等教育？为何扎堆技术领域？社会科学家发现，这最好地由**对制度性种族主义的务实回应**解释——"**种族歧视在技术职业中相对容易对抗，因为招聘与晋升有客观标准可依**"；模范少数族裔的最佳（也是孤注一掷的）身份**直接来自其被种族化的处境**："We know we are a minority in this society, and we have to do better than other Americans… That's the only way we'll get ahead."
- **对"追逐白人"叙事的批判**：把亚裔向上流动说成"almost white""out-white the whites"，是**贬抑性叙事**；更有用的概念是 Cheryl Harris 的**"白人性作为财产"与"名誉利益"**——身份带来系统性好处（住空气与水更干净、房价更高的社区，走维护良好的路，更好的零售选择与价格，得到保安、老师、雇主善意的怀疑豁免），而这些好处是**从联邦到市政层层立法**累积的产物。**模范少数族裔身份享有很多特权，只是不是白人特权。**

### 成功框架：从亚裔研究与临床经验中浮出
- 引用 Lee & Zhou 的《The Asian American Achievement Paradox》定义成功框架，并强调它**不只是目标清单，而是人格（personhood）的框架**：作为亚裔要在家庭聚会或教会社交中抬得起头，就得**按它生活**。
- 对许多第二代亚裔，这一框架是 **Gramsci 意义上的"常识"**：某些现实感知看似逻辑必然，实为文化特定、并服务于掌权者利益。"To be model minority is to 'know'… that success means hitting each of the achievement checkpoints in sequence, because *everyone knows*."
- **试金石不是收入或 GPA，也不是"世代的保证"**，而是：一个亚裔是否**依这些标准感到骄傲或羞耻**。若你曾为虎妈梗发笑（"笑得挺开心，也许还带着了然"），你的点赞、转发与分享就是在**认可一套身份**——"**our bar is higher**"。
- **身份跨越阶级**：贫困**不能豁免**于这些价值、感受与信念（举例：韩裔小商家之子的电影人 Justin Chon 谈 1992 年洛杉矶暴动与好莱坞忽视亚裔工人阶级）。**模范少数族裔的规训不挑人**：不论长子或幺儿、酷儿或异性恋、父母是否付得起小提琴课——"若你一无所有只剩勇气，那就更好（all the better）"。

### 亚裔美国人的异质性：框架为何能跨越差异
- 菲律宾裔：历经西班牙帝国、**以"被美国"（wards of the United States）地位**进入美国，在天主教与殖民史下路径独特；南亚裔：印度教或伊斯兰、英国殖民史数百年，与美国的"直接历史联系"最少。
- 但 Ninh 引用 Lee & Zhou 的**"第二代趋同"**：尽管第一代差异巨大，**华裔与越裔难民子女的教育结果在一代之内趋同**——**两个群体的受访者都复述同一个成功框架**。
- **课外教育的族裔密度依赖**：成功框架在**亚裔族群社区最稠密**处最旺盛——学生占比足以支撑教会网络、补习服务与文化活动的地区。Lee & Zhou 的田野是洛杉矶的圣盖博谷与橙县 ethnoburbs；Diane Wolf（"Family Secrets"）1990 年代在 Vallejo 的两所高中（菲裔占 25–30%、各族群中平均 GPA 最高）；Shalini Shankar 在硅谷的"Desi Land"（一个高中亚裔达 54%，约三分之一为南亚裔）；Pawan Dhingra 的 *Hyper Education*（2020，亚裔占 30% 以上、预计达 40–50% 的学区）。
- **这些是"新常态"**：亚裔卓越的**地方反文化**与主流美国种族思维争夺人心；它也**动摇了同化理论的假设**——"学术成就在种族上被编码为'亚洲人的事'"后，**白人性反而可能是负债**，而**模范少数族裔不像过去那样容易被写成"想变成白人"**。
- 但**并非单一模式**：有的地方（东岸、加州某些小镇）仍保有经典同化主义与旧式排斥；Wesley Yang《Paper Tigers》自认与自己的脸疏离；**Stuyvesant 高中亚裔占 72% 仍不保证"逆向经验"**；南亚裔在硅谷高中既玩"书呆子"也玩"酷小孩"（Shankar）；亚裔可以**同时**被视为高于或低于白人，且同样熟悉成功框架。

### 为何"例外"值得研究：Ninh 的伦理与认识论立场
- 这不是"根因裁决"（root cause），而是 **ethos 而非 biography** 的探究：**这种叙事的权力**——它如何训练自我的梦想与归属感，如何给失败标价。
- 作者强调不可能判定每一个案中"教养比例、种族化或潜在心理"如何导致决定性选择；也不该因"ratio"而自我安慰为"technically 不算失败者"。**例外不是为了计算错误率或定位生产流程的缺陷，而是为了暴露整条生产线（expose the industry itself）。**
- **性别问题**：已知的"伪装者"**全是女性**，而"诈骗者"多为男性。第四章（Bad Boys）不追问男女为何做出此选择，而是讨论**亚裔美国男性气质**如何被"模范少数族裔生活"的套路解释；并以 **Honor Roll Murder（Justin Lin 改编为《Better Luck Tomorrow》）** 为对照。

## 综合：三篇文献如何互补

| | **Lee & Zhou（2014）** | **Zhou & Lee（2017）** | **Ninh（2021，导论）** |
|---|---|---|---|
| **学科** | 社会学（质性访谈＋调查描述统计） | 社会学／社会心理学（同为 IIMMLA 数据） | 文学／文化研究（细读＋档案＋文化产物） |
| **核心问题** | 为何低 SES 的亚裔移民子女教育超预期？代价是什么？ | 文化的**结构性根源**是什么？为何"正面"刻板印象在职场反噬？ | 为何被成功框架养大的亚裔会走到**伪装（passing）**这步？ |
| **关键概念** | 成功框架、族群资本、框架、参照群体、成就悖论 | 超高选择性／低选择性、刻板印象承诺、竹子天花板 | 模范少数族裔作为身份、passing for model minority、残酷的乐观主义 |
| **对"文化解释"的态度** | 文化重要，但通过**框架＋族群资源**运作，非本质 | 文化有**结构根源**；"成功文化论"是"文化贫困论"的镜像 | 不否证"神话"，而是**进入**它的情感与道德经济 |
| **如何定义成功** | 应看**起点**与**代际流动**，而非只看结果 | 同上（墨西哥裔在代际流动上反而更成功） | 成功框架的**试金石是骄傲或羞耻**，不是数字 |
| **与黑人／其他群体的关系** | 参照群体是**高成就同族**，不是白人；"acting white"≠反成就 | 低选择群体（墨、苗）被超高选择群体的刻板印象**外溢**所误 | 模范少数族裔身份**不是"想变白"**，而是"制度性种族主义下的务实策略" |
| **共同敌人** | 虎妈式文化本质论 | 虎妈式文化本质论＋Pew 的因果误导 | "神话／事实"二分的框架本身 |
| **共同结论** | 解绑种族与成就 | 承认起点差异、重塑成功定义 | 把成功框架理解为人格框架，才有望"破她出地窖" |

**贯穿主线**
- **"文化"是被结构塑造的，因而是可变的**：1965 年移民法 → 超高选择性 → 成功框架＋族群资本＋刻板印象承诺 → 成就悖论 → 竹子天花板。三篇读起来是**同一条因果链的三个切面**（社会结构 → 群体资源 → 主观身份）。
- **代价与反噬**：成就的**同一机制**在生产盲点——参照群体导致永不自满（2014）、正面刻板印象导致领导力天花板（2017）、成功框架内化为不可退出的人格（2021）。
- **"模范少数族裔"不是描述，而是规范（norm）**：它规定了何为体面的亚裔人生，并让不服从者、达不到者承担耻辱与自我驱逐。
- **Ninh 的贡献**：把社会科学的"悖论"推进到**伦理与情感**层面——Lee & Zhou 从外部测量悖论，Ninh 从内部写出"**住在地窖里的孩子**"的感受；这也是她为何说本书是"前传"。

## 快速记忆口诀
- **一句话套三篇**：**移民法造出超高选择性 → 超高选择性造出成功框架与族群资本 → 成功框架在校园帮你、在职场困你、在心里锁你。**
- **Lee & Zhou 2014 的三个概念**：**框架**（Goffman 的透镜）＋**族群资本**（Borjas；补习班、SAT 冲刺班、流动原型）＋**成就悖论**（往上比较，永远不够）。代价＝**把族裔与成就绑在一起**（Paul／Andrew／Lana 疏远族裔认同，反而强化"族裔＝成就"的假关联）。
- **Zhou & Lee 2017 的两把尺**：**hyper-selectivity**（双重正选择：赢过原籍国不移民者＋赢过美国总体）vs **hypo-selectivity**（双重负选择）；以及 **stereotype promise**（正面定型带来的提升）vs **bamboo ceiling**（同一套定型在职场变成"好员工、坏领导"）。
- **成功不能被双重计算**：看**结果**，华裔最高；看**代际流动**，墨西哥裔最高——**比较必须连同起点一起看**。
- **Ninh 2021 的一句话**："**Model minority is not a myth; it is an identity.**"它是 Gramsci 意义上的**常识**，试金石是**骄傲或羞耻**；"passing for model minority"是**矛盾修辞**——**占住被派定的位置反而成为越界**。
- **Ninh 的三分法**：**scammers**（要好处，亚裔仅 11%）／**shammers**（不要好处，无现成脚本）／**passers**（第三类，才是全书要解释的）；**伪装者全是女性，诈骗者多为男性**。
- **Ninh 的方法论警句**：读**离群值**，如 Le Guin 的 Omelas——**真相不在平均数里，而在那个被关在地窖的孩子身上**；研究例外不是算错误率，而是**暴露整条生产线**。

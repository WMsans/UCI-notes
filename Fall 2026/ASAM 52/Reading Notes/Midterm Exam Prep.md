## §1.1a Zhou, Min, Anthony C. Ocampo & J. V. Gatewood —— "Contemporary Asian America: Immigration, Demographic Transformation, and Ethnic Formation"（*Contemporary Asian America*, 3rd ed., ch. 3, 2016）

**一句话主旨**：亚裔美国不是单一社群，而是 1965 年后移民潮造就的、**高度多元且以国外出生者为主**的人口；国籍来源、阶级与居住格局的差异造成**分化的命运（divergent destinies）**，这既推动泛族裔团结，也使其复杂化。

| 术语                                                            | 定义                                                                                |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **1965 年《哈特—塞勒法》（Hart-Celler Act）**                           | 废除国籍来源配额制，以**家庭团聚**与**技术劳工**为两大原则；本意方便欧洲人，实际到美国的大头是亚洲人与拉丁美洲人。                     |
| **1882 年《排华法》／"无权归化的外国人"（aliens ineligible for citizenship）** | 美国第一部纯粹以国籍来源排除整个群体的移民法；亚裔被剥夺归化、置产、从事专业职业、家庭团聚与通婚的权利。                              |
| **1943 年废除排华法 → 1945 年《战争新娘法》→ 1952 年《麦卡伦—沃尔特法》**             | 排亚体制的逐步拆解：1943 废除排华、1945 允许军人以非配额身份带入配偶子女、1952 取消种族作为归化障碍（但保留国籍配额）。               |
| **单身汉社会（bachelor societies）**                                 | 排亚法律下唐人街等地因无法家庭团聚而形成的男性为主社会。                                                      |
| **断裂／两极分化式同化（divergent destinies）**                           | 同一"群体"内部出现分化的流动轨迹；与**沙漏型经济（hourglass economy）**相连——底层缺乏技能者难以向上脱身。                 |
| **永久外国人（forever foreigner）**                                  | 不论个人如何同化，整个群体都被视为外来者的机制；处境由**外貌**而非文化适应程度决定（"你的英语说得真好"）。                          |
| **黄祸（yellow peril）**                                          | 每当美国与亚裔祖籍国发生冲突便重现的威胁叙事：日裔拘禁（9066 号行政令）、冷战疑华、**陈果仁（Vincent Chin, 1982）**、**李文和**案。 |
| **模范少数族裔神话（model minority myth）**                             | 掩盖群体内部贫困与高技能专业人士就业不足的刻板印象；政治功能是否定黑人的平等诉求（见 §2.1）。                                 |
| **涌现族裔性（emergent ethnicity, Yancey 等）**                       | 族裔性由**结构性位置与互动**产生，而非移植的文化，因而可以是情境性的、可动员的。                                        |
| **象征性族裔性（symbolic ethnicity, Gans）**                          | 可选择、表达性、闲余性的族裔认同；对亚裔**不完全适用**，因为"非族裔的美国人"不是他们的选项。                                 |
| **诠释性记忆（interpretive memory）**                                | 美国出生／1.5 代对从未亲身生活过的祖籍国的记忆，是其族裔认同的基础之一（另一基础是在美国的种族经验）。                             |
| **泛族裔性（panethnicity）**                                        | 跨越国籍来源的族裔聚合，以追求物质目的与增权；前提为共享文化／生活经验、被强加的共同对待、政治动员的需要（Lopez 与 Espiritu）。           |
| **三重压迫（triple oppression）**                                   | 亚裔美国女性主义者的立场：性别、种族与阶级不可分割。                                                        |

## §1.1b Espiritu, Yen Le —— "Coming Together: The Asian American Movement"（*Asian American Panethnicity*, ch. 2, 1992）

**One word**: Panethnicity

**一句话主旨**：泛亚裔认同**不是自然形成，而是被建构出来的**——"亚裔美国人"起初是外部强加的种族笼统化类别，1960 年代末被学生行动者重塑为**政治认同**与动员基础。

| 术语 | 定义 |
| --- | --- |
| **种族笼统化（racial lumping）** | 将所有亚洲人视为同质群体；既是排亚法律的种族主义基础，也是后来泛亚裔认同的来源。 |
| **族裔去认同（ethnic disidentification, Hayano）** | 刻意与某一被污名化的亚裔群体保持距离，以免被误认而受累（如排亚时期日裔与华人划清界限、二战时佩戴 "I'm Chinese" 徽章）。**结果是失败**：1924 年《移民法》把日裔降至他们所轻视的华人同等地位。 |
| **泛亚裔主义的三个前提（Lopez & Espiritu 补充后）** | ①共享文化价值与在美生活经验；②被社会强加为同一外貌群体的对待；③政治动员的内部需要；本书作者**补充**：快速转用英语与异族／异种族通婚增加。 |
| **文化企业家（cultural entrepreneurs）** | 自觉建构泛亚裔"文化社群"的行动者。 |
| **命名即象征政治（symbolic politics of naming）** | 拒斥 "Oriental"（殖民产物、刻板印象）而采用 "Asian American"（意味着政治行动主义与美国身份）；**黄种人权力（Yellow Power）**因菲裔抗议"我们是棕色，不是黄色"而被弃用，1972 年菲裔组成**棕色亚裔党团（Brown Asian Caucus）**。 |
| **AAPA（亚裔美国人政治联盟, 1968, UC Berkeley）** | 最早的泛亚裔政治组织之一，明确采取泛亚裔与进步立场（反战、第三世界团结）；其更名序列（Are You Yellow? → Oriental Concern → AAPA）体现不同意识形态。 |
| **使泛亚裔主义在 1960 年代得以扎根的五条件（必背）** | ①从移民人口变为本土出生人口（英语成为共同语言）；②战时／战后壁垒瓦解（民权法案、居住隔离下降）；③共同的受歧视经验（同工不同酬、玻璃天花板）；④民权／黑人权力运动＋亚洲反殖民民族主义＋越战；⑤新左派与第三世界团结。 |

## §1.2a Omi, Michael & Howard Winant —— "Racial Formation"（*Racial Formation in the United States*, 2nd ed., ch. 4）

**One word**: Racial formation

**一句话主旨**：种族不是固定、客观、生物性的本质，而是**被社会与历史地创造出来的范畴**，其意义在政治斗争中不断转化；种族同时属于**社会结构**与**文化表征**两个维度。

| 术语                                              | 定义                                                                                                         |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **种族形成（racial formation）**                      | 种族范畴被创造、栖居、转化与摧毁的社会历史过程。                                                                                   |
| **种族计划（racial project）**                        | 同时是①对种族动态的诠释／表征／解释，②沿种族界线重新组织与分配资源的努力；是种族形成与霸权的基本单位。                                                       |
| **社会结构（social structure）**                      | 社会关系被组织与统治的方式，种族是其构成要素而非例外。**宏观**：劳动力市场种族分层、居住隔离、国家政策；**微观**：日常生活中的种族判断。                                   |
| **常识（common sense）**                            | 种族被无意识地用来理解世界的框架；日常层面种族计划的运作方式。                                                                            |
| **霸权／反霸权（hegemony / counterhegemony, Gramsci）** | 统治通过强制与**同意**的结合维持；霸权既被维持，也被挑战与创造。                                                                         |
| **Phipps 案（开篇案例，第 53–54 页）**                    | 1982–83 年 Susie Guillory Phipps 起诉路易斯安那州要求由"黑人"改列为"白人"（按 1970 年州法 1/32 血统即算黑人）——**她败诉**；证明种族分类是法律与国家的社会建构。 |

## §1.2b Lowe, Lisa —— "Heterogeneity, Hybridity, Multiplicity: Marking Asian American Differences"（*Immigrant Acts*, ch. 3, 1996）

**One word**: heterogeneity, hybridity, multiplicity

**一句话主旨**："亚裔美国"绝不是同质、单一、固定的文化实体；用**异质性、杂糅性、多重性**三个概念命名群体内部的物质性矛盾，以瓦解"主流／少数族裔"的现行霸权关系。

| 术语                                      | 定义                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------- |
| **异质性（heterogeneity）**                  | 一个有边界范畴**内部的差异与差异关系**（如语言、阶级、代际的区隔）。                                            |
| **杂糅性（hybridity）**                      | 由**不均衡、非综合**的权力关系历史所生产的文化对象与实践；是不平等支配关系中"求生存"的痕迹，**不是同化**。                      |
| **多重性（multiplicity）**                   | 主体被资本主义、父权制、种族关系等**多重权力轴**共同决定。                                                 |
| **物质性矛盾（material contradictions）**      | 三个概念共同命名的对象——亚裔群体内部的真实物质差异，而非修辞问题。                                              |
| **subaltern（从属／底层阶级, Gramsci）**         | 不统一、前霸权、需事后回溯才能被理解的群体。                                                          |
| **新历史集团（new historical bloc, Gramsci）** | 由多个不同位置与实践协调而成、体现另一种霸权与权力平衡的关系集合。                                               |
| **政治形构（political formation, Davis）**    | 围绕议题／议程共同工作的政治集合——**政治先于认同**。                                                   |
| **拒绝"代际冲突"叙事**                          | 反对把亚裔经验简化为 nisei 母亲 vs. sansei 女儿式文化冲突；那会遮蔽阶级＋语言的区隔（如英语流利的华裔女监工 vs. 讲广东话的老年女工）。 |
| **vertical/horizontal identity models** |                                                                                 |

## §2.1a Lee, Robert G. —— "The Cold War Origins of the Model Minority"（*Orientals: Asian Americans in Popular Culture*, ch. 5, 1999）

**One word**: Model minority, Silent minority

**一句话主旨**：模范少数族裔神话**不是 1966 年由保守派凭空发明**，而是冷战时期自由派为美国全球霸权制造的同化叙事——亚裔被抬升，**与其说是亚裔真实成功，不如说是黑人未能（或拒绝）同化的投射**。

| 术语                                                             | 定义                                                                               |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **"Whites love us because we're not black"（Frank Chin, 1974）** | 全书枢纽句：亚裔在两层意义上"不是黑人"——**既不是白人，也不是黑人**，且**政治上沉默、族裔上可同化**。                         |
| **种族自由主义（racial liberalism）**                                  | 1940 年代起的信念：种族多样性最好通过**同化与整合**进白人中产阶级来管理；主张以国家干预推动民权。**自由派（而非保守派）才是模范少数族裔的发明者。** |
| **同化中的他者（assimilating Others）**                                | 被承认"能像白人一样行事"、但**种族上仍与他们有别**的人；亚裔由"无权归化的外国人"过渡到此中间位置，再到 1960 年代的"非黑人"模范少数族裔。     |
| **族裔性范式（ethnicity theory / ethnicity paradigm）**               | 以"族裔性"取代"种族"的自由主义理论：相信社会向所有人开放；歧视只是**不现代的残余**；同化是普遍、自然、不可逆的现代化过程。                |
| **帕克的种族关系循环（Park）**                                            | 四阶段、自然且不可逆：接触 → 竞争 → 适应 → 同化。                                                    |
| **戈登七阶段同化论（Gordon, 1960s）**                                    | 把帕克循环细化；并警告政府**不得积极使用种族标准**推行取消隔离。                                               |
| **福特主义妥协（Fordist Compromise）**                                 | 战后劳动与资本以高工资、福利国家换取劳工和平的安排，以**父权核心家庭**为消费基本单位——亚裔的"沉默少数"形象由此获得经济基础。               |
| **美国世纪（American Century）**                                     | 冷战新国家叙事：美国以种族同化的成功证明自身是自由民主典范与全球秩序领袖。                                            |
| **沉默少数（silent minority）**                                      | 亚裔的政治沉默被读成美德——"守法、勤奋、重视家庭、不抗议"，正是模范少数族裔的构成要件。                                    |
| **再表述（rearticulation, Omi & Winant）**                          | 把一个话语的核心要素**注入新的政治意义**并与保守派意识形态其他要素连接（见 §2.1b）。                                  |
| **paper sons／纸儿子与华人自首计划（Chinese Confession Program, 1957）**    | 排华时期以虚假身份入境者，在冷战反共审查中格外脆弱；1957 年计划鼓励自首但须供出所有亲友，供词被 FBI 用来遣返亲华／左翼人士。              |
| **《战争新娘法》（War Brides Act, 1945）**                              | 允许军人以非配额身份带配偶与子女入境，使"战争新娘"成为族裔同化的典范。                                             |

## §2.1b Osajima, Keith —— "Asian Americans as the Model Minority: An Analysis of the Popular Press Image in the 1960s and 1980s"（2005 原作 1988）

**一句话主旨**：模范少数族裔形象之所以能**经受批评与人口变迁而在 1980 年代仍居主导**，是因为它**承认批评、再把批评的力量最小化**，用一种"移动中停驻"的方式维持霸权。

| 术语 | 定义 |
| --- | --- |
| **1960 年代形象的两个基本要素** | ①**经验证据**：日裔／华裔教育成就居首、高地位职业、收入上升、精神病与犯罪率低；②**文化解释**：家庭凝聚、勤奋、纪律与延迟满足。 |
| **1980 年代的"纳异与批评"（incorporating change and dissent）** | 文章被更新、纳入新信息与批评，但**核心论断不变**——主导信息仍是"亚裔成功、以决心与勤奋克服歧视"。 |
| **"Tilting the Scale"：话语的三种操作机制（必背）** | ①**关键句赋予支持性信息"分析上的优先性"**（如以"所有研究都汇聚于此［家庭］"收尾）；②**用段落最小化矛盾信息**（承认中位家庭收入指标有问题，但四篇把它打折）；③**选择性地使用学术研究**（引用 Stevenson 等支持"家庭关键"的研究，**从不引用批评模范少数族裔的研究**，尤其不提"亚裔收入低于其教育水平应得"）。 |
| **霸权"以移动的方式停驻不动"（Gitlin）** | 霸权不靠否认批评来抵挡批评，而是承认批评、再以话语技术把其力量最小化。 |
| **2005 年（作者写作时）的持续性** | 亚洲经济崛起与"亚裔美国人"被表述为**经济威胁**的新叙事，仍沿用同一套刻板化逻辑（统一、勤奋、自给自足）。 |

## §2.1c Wu, Ellen D. —— "The Invention of the Model Minority"（*Routledge Handbook of Asian American Studies*, 2017）

**一句话主旨**：亚裔从"黄祸"到"模范少数族裔"是"美国历史上最引人注目的种族改头换面"，但学界把起源定在 1966 年、归因于白人保守派的说法**在四个方面不完整**。

| 术语                                       | 定义                                                                                                    |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **四种修正（Wu 的核心论证，必背）**                    | ①起点可追溯至**二战**；②发起者是**自由派而非保守派**；③根源既在**黑人自由运动**也在**美国对全球霸权的追求**；④聚焦主流媒体**遮蔽了亚裔美国人自身的同谋（complicity）**。 |
| **为什么承认"同谋"更诚实**                         | 凸显亚裔美国过去与现在的**政治多样性**；亚裔既参与制造这一刻板印象，也从其诞生起就站在**摧毁它**的前沿。                                              |
| **"确定地非黑人"（definitively not-black）**     | 1960 年代中期造出的模范少数族裔：**区别于白人多数**、但被赞赏为高度同化、向上流动、政治上无威胁、且**确定地不是黑人**。                                    |
| **美国在亚太的介入是模范少数族裔的关键引擎**                 | 自由派白人**同化（而非边缘化）**亚裔，恰恰**因为**他们被认为具有外国性——论证"在国内更善待亚洲人将加强美国在国外的联系"。                                    |
| **种族制造是关系性的（race making is relational）** | 亚裔／模范少数族裔的含义受当时对**黑人性与白人性**的理解塑造，反之亦然。                                                                |
| **日裔拘禁（1942–1945）**                      | 约 **12 万** Nikkei 被关押，是排亚体制的最低点；国家实际把每个日裔归为"敌国侨民"，战后才被重编为"忠诚的、可同化的"群体。                                |
| **华裔美国：反共、家庭价值与文化外交**                    | 冷战反共使华裔被表述为"忠诚的模范"；家庭价值观被用作文化外交证据。                                                                    |
| **夏威夷建州辩论**                              | 被当作全国性的"**亚裔公民身份公投**"——亚裔能否成为忠诚美国人，在此被国家尺度验证。                                                         |
| **1940–50 年代的全球 exigencies**             | 以民主之名对抗纳粹与法西斯使**赤裸的白人至上成为外交负担**，自由派因此着手拆解排亚体制（Asian Exclusion）。                                       |

## §2.1d Pew Research Center —— "The Rise of Asian Americans"（2012／2013）

**一句话主旨**：亚裔是美国**收入最高、受教育程度最高、增长最快**的种族群体，且最可能住在混合街区并跨种族通婚；但报告被亚裔学者批评为**选择性呈现**，诱导读者做出"价值观驱动结果"的因果推论。

| 概念／数据 | 说明 |
| --- | --- |
| **总体结论** | 亚裔比一般公众更满意生活、财务与国家方向，更重视婚姻、为人父母、勤奋与事业成功。 |
| **移民与语言** | 亚裔成年人 **74%** 在国外出生；其中约一半自认英语说得很好，一半不然。 |
| **跨种族通婚** | 近期亚裔新娘中 **37%** 嫁给非亚裔新郎。 |
| **六大亚裔群体的差异（合计 ≥83%）** | 华、菲、印度、越南、韩、日六大群体内部在教育、收入、贫困率上差距悬殊——**"亚裔"整体统计掩盖两极分化**。 |
| **历史与代际** | 一百年前多为挤在族裔飞地的低技能低薪劳工与官方歧视对象；如今多数为第一代，代际结构与其他族裔完全不同。 |
| **批评（Zhou & Lee 2017 的靶子）** | 强调亚裔更重视勤奋 → 诱导"文化价值决定社经结果"的误读（见 §2.2b）。 |

## §2.2a Lee, Jennifer & Min Zhou —— "The Success Frame and Achievement Paradox"（*Race and Social Problems* 6:1, 2014）

**One word**: framework

**一句话主旨**："虎妈"式文化本质论与地位获得／文化资本模型都无法解释亚裔移民子女的"超额"教育成就——**文化确实重要，但不是以本质主义的方式**：文化通过**框架**运作，框架需要**族群资本与族群资源**支撑；而这一框架有**代价**。

| 术语 | 定义 |
| --- | --- |
| **成就悖论（achievement paradox）** | 亚裔移民子女的教育成就**超出**家庭社经地位与主流文化资本所预测的水平；但同一批人在职场上**得不到**与同等教育白人相当的管理职位与回报。 |
| **成功框架（success frame）** | 移民父母传入的、关于"成功"的**严格定义与唯一路径**：全 A → 毕业生致辞代表 → 名校 → 高等学位 → 四大职业（医、法、工程、科学／药剂）。**不是亚裔天生固有，而是被超高选择性移民建构并推崇的**（见 §2.2b）。 |
| **框架（frame, Goffman 1974）** | 观察、诠释、分析社会生活的**透镜**；不直接导致行为，而是通过划定"**可能性地平线**"使某些行为变得可能或更可能。 |
| **族群资本（ethnic capital, Borjas 1992）** | 一个移民群体内部的**群体层面社经资源**（尤其受过大学教育的同族比例）；高族群资本使低社经地位父母也能让子女向上流动。 |
| **族群资源（ethnic resources）** | 族群资本的具体形态：族群经济中的工作与自雇机会；课后补习班、SAT 冲刺班、升学资讯；**流动原型（mobility prototypes）**——可见的高成就同族榜样。 |
| **地位获得模型（status attainment model, Blau & Duncan 1967）** | 父辈职业／教育是子辈成就最强预测项——**本章的靶子**，无法解释低社经亚裔子女的"超额"成功。 |
| **文化资本模型（cultural capital model, Bourdieu 等）** | 家庭传递的非经济资源在"门户制度"中被奖励；**局限：忽视家庭之外的情境因素（族群资本）**。 |
| **主流文化资本（dominant cultural capital, Carter 2005）** | 支配群体所看重的高地位文化信号与实践（博物馆、古典乐、钢琴小提琴、言语风格）。 |
| **参照群体（reference group）** | 亚裔第二代**不与白人、也不与美国平均比较**，而是与**最高成就的同族**比较——因此永远"不够成功"。 |
| **亚洲尺度／"Asian F"** | **A 是平均，B 是"亚洲式的失败"**；另一些版本："A 是 average，B 是 bad，C 是 crap，F 是 find another family。" |
| **刻板印象承诺（stereotype promise, Lee 2014）** | 被老师、辅导员、同侪**正面看待**为聪明、勤奋、值得时表现提升的效应——可成**自我实现的预言**。与 **刻板印象威胁（stereotype threat, Steele）**相对。 |
| **把族裔与成就绑定（coupling ethnicity and achievement）** | 代价之二：达不到标准者觉得自己是**族群异类（ethnic outlier）与失败者**，进而疏远同族与自身族裔认同，**反而强化"族裔＝成就"的虚假关联**。 |
| **解绑（decoupling）的四个好处** | 拆开族裔与成就的绑定，才能看见群体内部的差异、减轻失败者的羞耻、避免刻板印象外溢到其他群体，并让成功不再只有一条路径。 |

## §2.2b Zhou, Min & Jennifer Lee —— "Hyper-Selectivity and the Remaking of Culture"（*Asian American Journal of Psychology* 8:1, 2017）

**One word**: Hyper-selectivity

**一句话主旨**：亚裔教育成就**有结构性的根**——1965 年《哈特—塞勒法》之后的**高教育、高技能移民潮**；**超高选择性**说明移民群体的选择性本身如何**重塑文化**，并在个体家庭特征之外产生群体层面的优势（或劣势）。

| 术语 | 定义 |
| --- | --- |
| **正向选择性（positive selectivity, Feliciano 2005）** | 移民比**原籍国不移民者**受教育程度更高。 |
| **超高选择性（hyper-selectivity）** | **双重正选择**：某群体不仅比原籍国不移民者更可能大学毕业，**还比移居国总体人口**更可能大学毕业（如华裔）。 |
| **低选择性（hypo-selectivity）** | **双重负选择**：比原籍国不移民者**和**移居国总体人口的教育都更低（如墨西哥移民）。 |
| **文化贫困论 vs. 成功文化论** | 二者同时兴起、互为镜像：Lewis／Moynihan（1965）的"文化贫困论"解释黑人与波多黎各人的代际贫困；1966 年杂志话语的"成功文化论"把亚裔成就归因于家庭凝聚、勤奋、纪律与延迟满足。**两者都诉诸群体文化价值解释流动结果。** |
| **超高选择性的四重后果** | 产生群体层面的**族群资本与族群资源**、支撑**成功框架**、带来**刻板印象承诺**，以及职场上的**竹子天花板**（正面刻板印象反噬）。 |
| **竹子天花板（bamboo ceiling）** | 阻碍亚裔晋升高阶管理／领导职位的**隐形结构性障碍**，犹如女性的玻璃天花板。 |
| **用"起点"与"代际流动"重新定义成功** | 只看结果会误判；若看起点与代际流动，**墨西哥裔在代际流动上反而更成功**——"亚裔例外论"是统计幻觉。 |
| **刻板印象的外溢（spillover）** | 超高选择群体的正面刻板印象会**外溢**到低选择群体（墨西哥裔、苗族），使他们被误读为"不努力"。 |

## §2.2c Ninh, erin Khuê —— "Introduction: The Strange Case of the College Impostor"（*Passing for Perfect*, 2021）

**一句话主旨**：**"模范少数族裔"在"我的来处"不是一个神话**——拒绝"神话／证伪"框架，把它理解为一种**身份**（一套信念与抱负），并追问：被成功框架养育长大的亚裔，**为何会走到"完美伪装"这一步**？

| 术语 | 定义 |
| --- | --- |
| **模范少数族裔作为身份（model minority as identity）** | "一套信念与抱负，不论当下的社经地位或未来的可实现性"；不是关于收入或 GPA 的统计命题，而是关于成功的**正统信仰**："模范少数族裔就是要'知道'（哪怕同时憎恨它）成功意味着依序打中每一个成就检查点。" |
| **passing for perfect／passing for model minority** | "伪装"（passing）——不是"想变白"，而是**制度性种族主义下的务实策略**；伪装的对象是**完美**（成功框架的每一项检查点）。 |
| **scammers（诈骗者）** | 图**明确的物质利益**（现金、奖项、名校文凭），如假成绩单／推荐信、编造人生经历。**14 名非亚裔冒充者中 11 名（78%）属此类；9 名亚裔冒充者中仅 1 名（11%）属此类。** |
| **shammers（伪演者）** | 伪造**换不来物质利益**，且不套用现成社会脚本。 |
| **passers（伪装者）** | 第三类，**全书要解释的对象**；十年内美加媒体报道至少 **9 名亚裔**、**14 名非亚裔**大学冒充者——**比例上亚裔被过度代表**。 |
| **残酷的乐观主义（cruel optimism, Berlant）** | 依附于一个**同时阻碍你茁壮**的对象／承诺；成功框架正是如此。 |
| **covering（Yoshino）／述行性（performativity, Butler）／Double Agency（Tina Chen）** | 掩盖、演出、"perform[ing] themselves into being as persons recognized by their communities and their country"。 |
| **"the truth of a thing is in its outliers"（Le Guin, *Omelas*）** | 方法论声明：从**例外与离群值**中读出真相——不是流行病学、不是揭露（"this is not an exposé"）。 |
| **成功框架的试金石是骄傲或羞耻** | 不是数字：框架的效力体现在情感与道德经济中（见 §2.2a）。 |

## §3.1a Lahiri, Jhumpa —— "The Third and Final Continent"（*Interpreter of Maladies*, 1999）

**一句话主旨**：一个在三块大陆上安过家的孟加拉男人，克制地回顾自己 1964 年离开印度、经伦敦、1969 年抵达波士顿的旅程——**即使平凡的移民故事也是英雄的**，而"落脚"是一种**选择**而非被移植的必然。

## §3.1b Lee, Erika —— "From Asia to the United States, Around the World, and Back Again: New Directions in Asian American Immigration History"（*Oxford Handbook of Asian American History*, ch. 23, 2016）

**一句话主旨**：亚裔美国移民史正在"复杂化、拓宽与深化"——**先立方法**（重思"移民"、走向离散／跨国／全球框架），**再重述分期**（美洲起源 → 排亚时期 → 1945–65 的"盲点" → 1965 年至今）；副标题三短语就是结论。

| 术语 | 定义 |
| --- | --- |
| **推拉模型（push-and-pull model）** | 传统定义：原籍国的战争、灾害、动乱、经济不稳定"推"人出去，移居国的工资、土地、免于迫害"拉"人进来；假定个人做**自由、理性的决定**、移民是**单向**旅程、移民被"**连根拔起（uprooted）**"再"**移植（transplanted）**"并乐于同化。**这是 Erika Lee 全文要拆掉的靶子。** |
| **移民范式（immigrant paradigm, Gabaccia）** | 依赖"移民 → 适应美国"这条老路径；Gabaccia 主张改看移民"**持续的、多向的、循环的**"性格。 |
| **跨国／离散／全球框架** | 不再把亚洲移民史**只由美国民族国家**定义；追问移民跨越地理、文化、政治边界**持续维持**的社会关系与网络。 |
| **"流动的"取向（ambulatory approach, Hsu）** | 承认移民"复杂的协商、多层的现实、多向的取向"；台山人来回太平洋，"衣锦还乡"的退休有时又重返美国。 |
| **"双帝国"取向（two-empire approach, Azuma）** | 把日本人向美洲的劳工移民与日本在亚洲的**殖民扩张**连起来"重新绘制（remapping）"；移民夹在美、日两个帝国之间。 |
| **亚洲人在美洲（Asians in the Americas, Hu-DeHart）** | 把亚裔美国史放进美洲范围（墨西哥、古巴、秘鲁、加勒比）的亚洲人历史框架。 |
| **马尼拉大帆船贸易（Manila galleon trade, 1565–1815）** | 第一次把欧洲、亚洲、美洲连成**跨太平洋贸易网**；估计把 **4 万–10 万**菲律宾人、中国人、日本人运往新西班牙。**迟至 1860 年，拉丁美洲与加勒比的中国人都比北美洲多。** |
| **苦力贸易（coolie trade）** | 1847–1874 年把 **25 万**中国契约劳工运往古巴与秘鲁；1834–1918 年把 **43 万**南亚人运往英属西印度群岛。与**黑大西洋奴隶制世界**相连，是奴隶制向自由劳动过渡的一环。 |
| **门户国家（gatekeeping nation）** | 排华法不仅改变华人的生活与家庭，也把美国**重新铸造**成以**身份查验、边境执法、监视与驱逐**为核心的国家。 |
| **"非法外国人"（illegal alien, Ngai）** | 1930 年代菲律宾遣返计划、二战日裔拘禁、持假证件的"纸儿子"——这些被当作政策"问题"的群体，反过来塑造了关于种族、国家认同、公民身份与国家权力的观念。 |
| **排亚法律六连（必背）** | ①**1875《佩奇法》**（Page Law）②**1882《排华法》** ③**1907《君子协定》** ④**1917《移民法》"亚洲禁区（Asiatic Barred Zone）"** ⑤**1924《移民法》**（禁止"无权归化的外国人"入境）⑥**1935《泰丁斯—麦克杜菲法》**（把菲裔从"美国国民"重新分类为受排外法管辖的外国人）。 |
| **paper sons／paper families（纸儿子／纸家庭）** | 排亚时期以虚假身份文件（声称是美国公民之子）入境的华人；Estelle Lau 研究的"纸家庭"。 |
| **picture brides（照片新娘）** | 靠照片相亲而成婚移民的妻子，是排亚法律下日本移民**仍能组建家庭**的缝隙之一。 |
| **"排亚期间移民仍在继续"** | 新史学的关键发现：纸儿子／纸妻／纸女、照片新娘、韩国劳工／学生／家庭、南亚劳工／学生／革命者、以"美国国民"身份入境的菲裔——**法律没有关上门，人从缝里进来**。 |
| **军人新娘与营镇（military brides / camptowns）** | 1950 年后驻韩美军基地周边由美军"支持并管理"的营镇；**近 10 万**韩国军人新娘在 1950–1989 年间移民美国（Yuh：置于 1950 年后韩美之间新帝国主义的、性别化的关系里）。 |
| **历史盲点（historical blind spot）** | 1945–1965 这二十年长期被史学忽视；新研究证明**军人新娘、学生、难民、专业人士、被收养者**在这段"空白"里奠定了当代亚裔社区的基础。 |
| **跨国收养／"模范被收养者"（model adoptees）** | 1953 年以来超过 **11 万**韩国儿童被美国收养（全球约 20 万），在韩国被建制化为"国家习俗"；1990 年代转向中国，女婴被描述为没有原生家庭牵连、族裔背景"合意"、种族地位"灵活"。 |
| **冷战的专业人才通道** | 1950 年代台湾、香港精英华人科学家与工程师赴美；"交流访客计划"送来精英菲律宾护士，为 1965 年后的大规模护士移民开门。 |
| **1965 年《移民与国籍法》（Hart-Celler Act）** | 废除国籍来源配额，设**家庭团聚**与**技能劳工**两大目标；本意方便欧洲人，实际大头是亚洲人与拉丁美洲人。 |
| **"太空人"／"降落伞儿童"／分裂家庭（astronaut / parachute kids）** | 港台家庭跨太平洋拆分；与排亚时期被拆散的家庭相似，但**今天能来回飞**——电邮、国际电话与互联网让跨国联系更密。 |
| **弹性公民（flexible citizens, Aihwa Ong）** | 拥有多套房产与多本护照、享有多国特权通行的跨国华人精英。 |
| **balikbayan／汇款（remittances）** | 美国菲律宾永久居民因每年汇回数十亿美元被誉为国家英雄；"跨国慈善"已组织化（数千个同乡会与协会）。 |
| **海外印度人卡（PIO Card, 1999）／NRI** | 印度给"非定居印度人"免签访印、置产、买国债、报考印度大学的权利——把国民权利授予非国民以换投资与纽带；2005 年印度收到 **270 亿美元**汇款："NRIs are the new VIPs." |
| **难民假释计划（Indochinese Parole Programs）** | 司法部长以临时紧急名义"假释"外国人入境，**没有数量上限、不受国会监督**；1978–1980 年据此接收 **267,800** 名难民。 |
| **批判难民研究（critical refugee studies, Espiritu）** | 强调**美国帝国主义**如何**生产出"难民"这一主体**，以及**记忆**在保存东南亚裔美国人历史中的作用。 |
| **离散意识（diasporic consciousness, Yuh）** | 海外韩国人的离散意识日益"**以离散、而非祖籍国为参照点**"。 |

## §3.2 Cheng, Wendy —— *The Changs Next Door to the Díazes: Remapping Race in Suburban California*（导论 + 第一章，2013）

**一句话主旨**：Cheng 提出**区域尺度的种族形成理论**——**日常景观**是种族等级被学习、实例化与转化的关键场域；在她研究的洛杉矶县西圣盖博谷（亚裔占五分之三、拉丁裔近三分之一的**郊区多数非白人**地带），**地方特定的知识**能提供**替代霸权意识形态的世界观**。

| 术语 | 定义 |
| --- | --- |
| **区域种族形成（regional racial formation）** | 在 Omi 与 Winant 的"种族形成"之上，强调**地方特定的（place-specific）**过程：地方上被接受的种族秩序与等级会**复杂化、有时挑战**霸权意识形态与简单化的种族观念；关心全国性过程如何**落在更小尺度**（邻里、地方、区域）中，而**这些尺度本身也是被生产出来的**。 |
| **沉积（sedimentation／"一个地方累积的历史"）** | 地质隐喻：社会关系在景观中一层层沉积；任一景观只有**最上层可见**，但下面各层的过程**仍塑造着最上层**，随时可能引发位移与断裂。 |
| **区域常识（regional common sense）** | 区域尺度上形成的葛兰西式"常识"，**临时的、日常的、不断变动的**；即使既定结构不变，区域实践仍可能超出民族国家框架所能规定的东西。 |
| **区域种族等级（regional racial hierarchies, Pulido）** | "正是在区域或地方尺度上，关于种族与阶级关系的更细致的讨论才浮现出来"；种族等级由地方人口结构、区域经济、地方历史与更大尺度意识形态共同塑造。 |
| **差别种族化（differential racialization）** | 不同的种族意义被附着在不同群体上，带来**法律、社会与经济的深刻后果**。 |
| **"纯空间"的道德地理／白人空间想象（Lipsitz）** | 源自边疆意识形态，把**通过财产产生交换价值**置于一切之上。 |
| **"差别化空间"的道德地理／黑人空间想象（Lipsitz）** | 由"被侵害的有色社群"发展出，推崇**使用价值与公共／社群善**。注：黑／白**不是字面肤色**，而是**两种意识形态立场的能指**。 |
| **种族化特权（racialized privilege, Cheng）** | **一个非白人群体相对于其他非白人群体**、在特定语境下享有的更高期望与更多机会；**不同于白人特权**，因为它**依赖而非否定种族他者性**（如西圣盖博谷学校中亚裔相对于拉丁裔学生的优势）。 |
| **策略性地使用白人身份（strategic use of whiteness）** | 亚裔与拉丁裔对"荣誉白人／模糊白人"身份的策略性运用；但**未忘记历史与结构性种族主义**，且常与强烈的非白人认同并存。 |
| **涌现的"非白人"认同（emergent nonwhite identity）** | 根植于**郊区邻里空间**、有别于传统上根植于**工人阶级与城市中心**的 "people of color" 认同；特征是不断变化的联盟、政治后果不确定。 |
| **永久外国人 vs. 荣誉白人 vs. 模糊白人／非法外国人** | 亚裔：既被相对抬高（模范少数族裔／荣誉白人），又被"永久外国人"化。墨西哥裔：法律上是**模糊的白人**（1848 年《瓜达卢佩—伊达尔戈条约》后获美国国籍＝法律上的白人），但被"外国人"化并加上廉价劳工的阶级污名，20 世纪下半叶被种族化为**原型"非法外国人"**。 |
| **白人身份即财产（whiteness as property, Cheryl Harris）** | 白人性与财产的观念互补绑定，共同生产与维系美国的物质性种族不平等。 |
| **市场 imperative（David Freund）** | 战后白人房主以"市场逻辑／无种族色彩的自身利益"为种族隔离辩护；"白人、房主、公民"三词被混为一谈。 |
| **民用社会制度（institutions of civil society, Althusser）** | 学校、教会、社区组织等；在**中立与平等主义的掩护下**把特定秩序正常化为"常识"，既是意识形态斗争的**赌注**也是**场所**。 |
| **感觉结构（structures of feeling, Williams）** | "被实际生活与感受到的意义与价值"——此时仍在意识形态上不可想象、却已停在语义可用性的最边缘。 |
| **认知地图（cognitive mapping, Jameson）** | Cheng 的第二种方法：让受访者画出自己日常／每周路线的**个人地图**，以理解同一地区不同种族者的空间经验差异。 |
| **族裔飞地／族裔郊区（ethnoburb, Wei Li）** | 过渡性的多族裔空间：**阶级多样、正式与非正式族裔商业网络并存**。 |
| **"双管齐下"解决方案（two-prong solution）** | 全球资本主义重构同时寻求**技术创新＋廉价劳动力**；亚裔移民**同时参与两半**——既提供技术领域高学历人才，又与拉丁裔移民一起做低薪工作。 |
| **新的多族裔多数（new polyethnic majority, Kurashige）** | 种族"进步"不应再被理解为融入白人多数，而应"振兴为一场建构新的多族裔多数的运动"。 |
| **差别化的财产准入（differentially racialized access to property）** | 第一章核心：1950–70 年代亚裔与墨西哥裔得以在**相对开放但绝非中立**的西圣盖博谷买房，其准入**建立在反黑人种族主义之上**，并在**差别化协商**中进行。 |
| **法律禁止了歧视，实践仍排斥** | 法律时间线 **1948／1963／1964／1968**；机制：**unpublished agreement（私下协议）、racial steering（种族引导）、"go back where you came from"**。 |
| **"模范少数族裔"与"模糊白人"的条件性接纳** | 用 **Tong 一家**（"an engineer and a teacher"）、**Padilla 一家**（"So all of a sudden, we were OK"）与 **1993 年 Alvarez 一家**（白人卖方拒售亚裔、偏好墨西哥裔）说明：接纳是**有条件的**，取决于"通过"或展示与财产的"正当"关系。 |

# 第5章：既分离又相聚：群体生活
## 核心定义（必须牢记）

| 术语                                  | 定义                                                                                           |
| ----------------------------------- | -------------------------------------------------------------------------------------------- |
| **群体（Group）**                       | **两个或两个以上的人，他们共享某种属性、彼此认同，并拥有持续的社会关系**（例如家庭、星际迷航粉丝俱乐部、足球队、姐妹会、每月一起打扑克的朋友）。                   |
| **人群（Crowd）**                       | **在公共场合临时聚集的一群人**；成员之间可能互动，但彼此并不认同，散去后也不会保持联系（Goffman 1971）。                                 |
| **聚合体（Aggregates）**                 | **共同处于某一特定物理地点、但没有持久社会关系的人群**（人群、观众、排队的人）。                                                   |
| **类别（Category）**                    | **共享一种或多种属性、但缺乏共同身份认同或归属感的人**（所有18岁的人、所有韩裔美国男性、所有雪佛兰皮卡车主）。                                   |
| **初级群体（Primary groups）**            | （Cooley 1909）由**对我们的自我意识最重要的人**组成的群体；成员关系通常以**面对面互动、高度合作和强烈的归属感**为特征（家庭、密友）。                 |
| **次级群体（Secondary groups）**          | **比初级群体更大、更不亲密**的群体；成员关系通常围绕**特定目标**组织，且往往是暂时的（同事、大学班级、工会、政党）。                               |
| **重要陌生人（Consequential strangers）**  | （Blau and Fingerman 2009）我们并不认为很亲近、但在日常生活中**扮演重要支持角色**的人——咖啡师、健身房的熟人、收银员；介于初级与次级关系之间的"社会锚点"。 |
| **社会网络（Social network）**            | **将个体与其他可能影响该个体的人连接起来的直接与间接关系之网**。                                                           |
| **社会纽带（Social ties）**               | **个体之间的联系**；可以是**直接的**（你和你的朋友），也可以是**间接的**（你和你朋友那位素未谋面的表亲）。                                  |
| **中心性（Centrality）**                 | 社会网络分析术语，指**在给定网络中拥有最多纽带的行动者**；中心性本身就能带来影响力，无论输赢。                                            |
| **失范（Anomie）**                      | （Durkheim）**"规范缺失"**；因社会纽带减弱和变化加速而产生的疏离感与目标丧失。Durkheim认为群体规范限制了我们的欲望；没有规范，我们就会与社会脱节，甚至可能自杀。  |
| **虚拟社群（Virtual communities）**       | 通过**信息技术，尤其是互联网**为媒介进行互动的社会群体。                                                               |
| **群体动力学（Group dynamics）**           | **群体与个体之间互动的模式**——群体如何形成、变化、解体、达成伟大目标或犯下可怕错误。                                                |
| **二人群体（Dyad）**                      | （Simmel）**最小的社会群体**：**只有两名成员**；关系亲密，但根本上不稳定，因为只要一个人退出，群体就结束了。                                |
| **三人群体（Triad）**                     | **由三人组成的社会群体**；比二人群体稍稳定，因为第三个人可以**调解**另外两人之间的冲突。                                             |
| **内群体（In-group）**                   | 个体**认同并感到忠诚的群体**；成员往往对外群体感到有别于己、甚至怀有敌意。                                                      |
| **外群体（Out-group）**                  | 个体对其感到**对立、竞争或敌意**的群体。                                                                       |
| **过渡仪式（Rite of passage）**           | 标志个体**从一种群体成员转变为另一种群体成员**的仪式（如入会仪式、新兵基础训练）。                                                  |
| **降格仪式（Degradation ceremony）**      | （Garfinkel 1956）一种**剥去个体先前身份**、为进入新群体做准备的仪式（剃头、统一制服、给新兵起贬义绰号）。                               |
| **参照群体（Reference group）**           | 为个体提供**自我评价标准**的群体——包括我们渴望加入但尚非其成员的群体。                                                       |
| **群体凝聚力（Group cohesion）**           | 个体对其所属群体所感到的**团结感或忠诚感**；把成员凝聚在一起的力量。                                                         |
| **群体思维（Groupthink）**                | （Janis 1971, 1982）在高度凝聚的群体中，倾向于**强制高度一致**，造成对全体一致的要求，压制批判性思考。                                |
| **社会影响（Social influence）**          | **同伴压力**；群体对他人决策的影响。我们之所以从众，通常是因为想要**接纳/认可**，并避免**拒绝/反对**。                                   |
| **顺从（Compliance）**                  | **最轻微**的从众：因为预期能**获得奖励或避免惩罚**而随大流，但并不真正改变自己的信念。                                              |
| **认同（Identification）**              | **较强**的从众，由个体**建立或维持与某人或某群体关系**的愿望所引发；因为认同该群体而遵从群体的意愿。                                       |
| **内化（Internalization）**             | **最强、最持久**的从众：把领导者或群体的信念**当作自己的信念**；信念与行为合而为一。                                               |
| **社会惰化（Social loafing）**            | **随着加入任务的人数增加，每个人付出的努力反而减少**的现象；是团队合作效率低下的一个来源（Karau and Williams 1993）。                     |
| **社会认同理论（Social identity theory）**  | 强调成员需要**获得归属感**的群体形成与维系理论；最有效率的团队以成员间最大的共享社会认同为特征（Turner and Reynolds 2010）。                 |
| **权力（Power）**                       | **控制他人行动的能力**。                                                                               |
| **强制权力（Coercive power）**            | **以武力威胁为后盾**的权力。                                                                             |
| **影响力（Influential power）**          | **以说服为支撑**的权力。                                                                               |
| **权威（Authority）**                   | **合法行使权力的权利**；大多数正式组织都会以某种公认形式将其制度化。                                                         |
| **传统型权威（Traditional authority）**    | （Weber）基于**习俗、出身或神授权利**的权威（君主制、王朝）。                                                          |
| **法理型权威（Legal-rational authority）** | （Weber）基于**法律、规则与程序**的权威，而非某个领导者的血统或人格（现代总统制、议会制）。                                           |
| **魅力型权威（Charismatic authority）**    | （Weber）基于**对领导者非凡个人品质的感知**的权威；可以是革命性的。                                                       |
| **工具型领导（Instrumental leadership）**  | （Parsons and Bales 1955）**以任务或目标为导向**的领导。                                                    |
| **表达型领导（Expressive leadership）**    | 注重维持**群体内部情感与关系和谐**的领导。                                                                      |
| **科层制（Bureaucracy）**                | 一种**旨在高效完成任务的特殊次级群体**，以专业化、技术能力、层级制、成文规则、非人格化和正式书面沟通为特征（Weber）。                              |
| **理性化（Rationalization）**            | 将**经济逻辑应用于人类活动**；运用正式规则与规章以最大化效率，而不考虑主观或个人关切。                                                |
| **麦当劳化（McDonaldization）**           | （Ritzer 1993）**科层理性化向日常生活蔓延**，伴随效率的提升**与非人性化**的加剧。                                           |
| **荣誉谋杀（Honor killing）**             | **杀害被认为给家庭或社群带来耻辱的家庭成员——通常是女性**；行凶者被视为规范的执行者，而非规范的违反者。                                       |

## 📍 章节开篇：入会仪式与群体的力量

- **FAMU"行进100"乐队大巴事件（2011年11月19日）：** 鼓手长**Robert Champion**在一场残酷的入会仪式中丧生——他被盖着毯子，在乐队大巴后部遭到鼓槌、鼓棒和皮带殴打。入会仪式旨在**考验新人并将其转变为群体成员**；忍受虐待被视为"有资格属于这个群体"的证明。
- **后果：** 12名乐队成员被控过失杀人，4人最终入狱；乐队被停演近两年；乐队指挥被解雇；FAMU校长辞职；Champion的家人赢得110万美元过失致死赔偿与道歉，并成立了**Robert D. Champion "Drum Major for Change" Foundation**。
- **社会学之问：** 一些乐队成员辩称，Champion和其他学生**自愿**接受入会仪式，因为他们想在乐队中晋升到领导位置。当入会仪式导致违法、受伤甚至死亡时，责任究竟在群体还是个体？
- **入会仪式事实：** 在几乎所有州都违法，通常也被群体章程禁止，但在兄弟会、姐妹会、运动队、社团、乐队、教会团体、警察/消防部门和军队中仍然常见；自1970年以来，美国大学生中已有**150多起**入会致死事件；专家估计约**80%**的事件中酒精是重要因素（Nuwer 2018, 2019）。
- **为什么重要：** 和所有灵长类动物一样，我们是**社会性动物**——群体帮助我们生存，但也可能让我们做出独自一人时绝不会做的事。本章探讨**群体动力学（Group dynamics）**，以理解群体生活的益处与危险。

> **启示：** 群体成员身份塑造身份、行为甚至生命本身。理解群体有助于解释社会生活最好*与*最坏的一面——从团结合作到入会仪式和群体思维。

## 1. 什么是群体？

### 社会学定义
- 日常用法：任何有一群有共同点的人。**社会学用法：** 至少两个人，既共享某种属性，**又**彼此认同，**并且**拥有持续的社会关系。
- **在社会学意义上不属于群体的例子：**
  - **人群/聚合体**——旅游景点的游客、围观火灾的人：他们虽有互动，但缺乏共同身份，散去后不会再次聚集。
  - **类别**——18岁的人、韩裔美国男性、雪佛兰皮卡车主：共享某种属性，但不经常互动，也没有共同的联系感。
- **群体 vs. 聚合体/类别：** 群体能形成**持久的社会关系**。

### 初级群体与次级群体
- **初级群体（Primary groups）**（Cooley 1909）：亲密的、面对面的、合作的、情感上至关重要的群体——家庭和密友。它们之所以是"初级"的，是因为对我们影响最为深刻：它们提供情感满足、我们的大部分社会化，并在人的一生中始终居于身份认同的核心。它们是我们最重要的**"镜中自我"**和**重要他人（significant others）**。
- **新冠例子：** 封锁期间，初级群体——尤其是家庭和同住者——成为支持、社交和反馈的主要来源。
- **次级群体：** 更大、更不亲密、更正式、更非个人化，通常围绕任务或活动组织——同事、大学班级、体育组织、工会、政党。成员关系往往是暂时的，情感满足也较少。
- **界限模糊：** 次级群体常常产生初级纽带（在工作中结识的朋友）。你的足球队可能既有目标导向，*又*对你有个人意义——现实生活比类型学更复杂。

### 重要陌生人
- （Blau and Fingerman 2009）我们不仅需要亲密朋友：熟悉但不算亲近的人——咖啡师、健身房的熟人、收银员、美甲师——在碎片化的后现代生活中充当**社会锚点（social anchors）**。
- **要点：** 我们需要初级关系、次级关系，**以及**介于两者之间的连续谱，才能在环境中最佳地运作。

### 社会网络
- **社会网络（Social network）** = 将个体与他人连接起来的直接与间接关系之网。
  - **直接纽带（Direct ties）：** 你 ↔ 你的朋友。
  - **间接纽带（Indirect ties）：** 你 ↔ 你朋友的表亲（经由你的朋友）；可以包括商品、服务、金钱、思想的流动，甚至跨越数百年的古希腊哲学。
- **"六度分隔"（six degrees of separation）：** 理论上，每个人都可以在六步之内连接到世界上任何其他人（认识100人 → 1万人的朋友的朋友 → 3度时100万人 → 6度时90亿人）。
- **Duncan Watts**（《六度：互联时代的科学》, 2003）： 网络结构塑造行动——例如，如果足够多的朋友投给另一位候选人，我们可能会改变自己的投票。网络分析有助于解释时尚与潮流的传播、求职信息以及疾病传播。

#### 赢家、输家与影响力
- **Joseph Conti**（WTO研究）： 美国参与了绝大多数贸易争端，但通常输掉；真正重要的是**中心性（centrality）**——拥有最多的联系——而不是输赢。中心性本身就是强大影响力的来源。

#### 工作、不平等与网络
- **Mark Granovetter**，《弱关系的力量》（1973）： 弱关系——连接不同网络的熟人——对求职至关重要。同质化网络（相同的种族、阶级、宗教等）限制了对新信息的获取。
- **Hoffman and Torres**（2002）： 网络中男性较多的女性更容易听到好的工作线索；网络中女性较多的女性则更难听到高质量工作机会。男性网络不受同样影响。解释：女性听到工作线索的可能性本来就较低，*而且*出于工作不安全感，女性更可能把线索传给男性。
- **Pedulla and Pager**（2019）： 黑人与白人求职者使用网络的概率相同，也都从中受益，**但白人受益更多**。黑人求职者的网络更不可能包含目标公司的人，也更不可能有人替他们联系目标公司 → 社会网络可以再生产种族不平等。

#### 性健康与网络
- **Christakis and Fowler：** 所有社会网络都有**连接**；**传染（contagion）**就是通过社会纽带流动的东西（肥胖、吸烟、药物滥用、性病）。
- STD例子：伴侣多的人往往与伴侣多的人发生性行为，使性病集中在"核心群体"中。

#### 新冠：检测、追踪与溯源
- 流行病学本质上基于社会网络。**康奈尔研究（Weeden and Cornwell 2020）：** 几乎所有本科生之间只隔**两名其他学生**；大学校园是"小世界" → 促使许多高校在2020年秋季选择线上教学。
- **接触者追踪（contact tracing）** = 采访感染者、追踪接触者、通知他们；循环往复。美国公共卫生部门往往不堪重负、检测不足；韩国利用手机数据、无现金交易记录和监控摄像头做得更好（隐私法律也更灵活）。控制人口因素后，美国的新冠病例数是韩国的**47倍**，死亡数是**79倍**（Solano et al. 2020）。
- 监测网络中的**中心个体（central individuals）**可以提前预警疫情暴发。

## 2. 与群体分离：失范还是虚拟成员？

- **Durkheim的洞见：** 群体规范给我们的个人欲望设置了**界限**。没有界限，我们会无休止地追逐得不到的东西，变得极度不快乐。
- **失范（Anomie）** = 规范缺失；一种与群体生活脱节的感觉。Durkheim相信，群体成员身份把我们锚定在社会世界中——**并让我们活下去**。
- 现代社会的碎片化令Durkheim担忧：快速的技术与文化变迁可能削弱社会纽带、加剧失范，甚至导致自杀。

### 📡 未来之窗：虚拟世界中的群体纽带会变成什么样？
- **虚拟现实（VR）**（Oculus Rift，Facebook/Google/Sony/Microsoft）创造沉浸式3D视觉与声音体验；Zuckerberg想象在家戴上护目镜就能享受场边座位、全球课堂、与医生面对面咨询。
- **潜在益处：** 让艺术、教育、医疗、旅行更民主化；增进跨文化共情（联合国首部VR影片《锡德拉的云》让观众进入约旦扎塔里难民营）；全身感应服可以模拟触觉。
- **大问题：** VR会让阶级化的消费准入变得更平等，还是会复制现实世界的不平等？它会让我们更亲近，还是更疏远？在VR中做事与在"肉身空间"中做同一件事一样吗？VR将如何影响教室、家庭和人际关系？

### Putnam之争
- **Robert Putnam**，《独自打保龄》（Bowling Alone, 2000）： 美国人不再像过去那样参加保龄球联赛、家长教师协会、基瓦尼斯俱乐部、女性选民联盟或打桥牌——这是**公民参与（civic engagement）** 和社区纽带的衰退，而这些本可抵御失范。
- **批评者：** Putnam可能美化了"美好的旧时光"；新技术和在线群体提供了替代性的连接方式。
- **数字时代之忧：** 互联网可能让我们更孤独，用"更广但更浅"的在线联系取代深厚的面对面纽带（Marche 2012）。连曾是乐观派的**Sherry Turkle**（2011, 2015）也警告，我们已把技术置于关系之上。
- **反证（皮尤研究中心、Klinenberg、Fischer）：** 社交媒体用户可能*更*有连接、更信任他人、更政治参与；美国人并不比以前更孤独或更疏离。
- **虚拟社群（Virtual communities）：** 大型多人在线角色扮演游戏（魔兽世界、堡垒之夜）、在线互助小组、粉丝社区——技术提供了新的归属方式。
- **警告：** 把社交媒体当作逃避社会痛苦的"逃生机制"，反而会增加孤独感（Nowland, Necka, and Cacioppo 2017）。新冠封锁期间，与**至少五位密友或家人**保持联系的人孤独感增幅较小；面对面互动仍然优于媒介化互动（Kovacs et al. 2021）。
- **历史的回声：** Durkheim曾担心工业革命会让人与人疏离；今天我们对数字时代也有同样的担忧。快速的技术与社会变迁总会引发焦虑。

## 3. 群体动力学

- **群体动力学（Group dynamics）** = 群体如何形成、变化、解体、达成伟大目标或犯下可怕错误。关键问题：群体如何影响自我？什么把成员凝聚在一起？群体如何影响成员？群体何时表现卓越？领导者有何特质？群体何时对个体具有破坏性？

### 二人群体、三人群体与更大群体
- **二人群体（Dyad）**（2人）：亲密但**不稳定**——只要一个人离开，群体就消失。
- **三人群体（Triad）**（3人）：更稳定，因为第三人可以**调解冲突**。
- **更大群体：** 随着人数增加，不是每个人都能认识其他人 → 群体变得更**正式、规则化、层级化**。
- **公理：** 群体越小，越可能基于个人纽带；群体越大，越可能基于规则与规章。

### 内群体与外群体
- **内群体（In-group）** = 我们认同并对其忠诚；**外群体（Out-group）** = 我们对其感到对立、竞争或敌意。
- **"我们 vs. 他们"强化了忠诚与凝聚力**，但也助长偏见、刻板印象与歧视（阶级、种族、性别、性取向、宗教、政治观点）。
- **Robert Merton**（1968）： 同样的行为在"我们"这里被视为正面，在"他们"那里却被视为负面——*我们*是"随和"，*他们*是"懒惰"；*我们*是"有品位"，*他们*是"势利"；*我们*是"虔诚"，*他们*是"狂热分子"。
- 内/外群体动力学最好时产生团结与忠诚，最坏时成为奴隶制和种族灭绝等社会悲剧的背景。
- **过渡仪式（Rite of passage）**把外人转化为内部人。入会仪式是一个例子；**降格仪式（Degradation ceremony）**（Garfinkel 1956）剥离旧身份——新兵被剃同样的头、穿同样的制服、被叫贬义绰号（"新兵蛋子"等），直到赢得老成员的尊重。

### 参照群体
- 提供**自我评价标准**的群体——同伴、职业群体、名人、虚构角色。
- 我们对照参照群体问自己：我够好吗？够聪明吗？够快吗？
- 参照群体可以是**我们渴望加入但尚非成员**的群体（未来的护士/律师审视自己的职业）。

> **📋 数据工作坊——分析日常生活："二十项陈述测验：我是谁？"**
> **TST**（Kuhn and McPartland Kuhn and McPartland 1954）测量自我概念在多大程度上基于群体成员身份。
> - 在5分钟内写下**20条**对"我是谁？"的回答。
> - **按四种模式计分：**
>   - **A模式：** 身体特征（"我很矮"、"我是金发"）。
>   - **B模式：** 与社会角色/地位相关、通常与群体成员身份相连（"我是学生"、"我是女儿"、"我是天主教徒"）。
>   - **C模式：** 个人特质、行为风格或情绪状态（"我很快乐"、"我有竞争力"）。
>   - **D模式：** 抽象/存在性（"我就是我"、"我是宇宙的一部分"）。
> - **Zurcher（Zurcher 1977）：** 早期美国人更多是**B模式（"制度性"）自我**——以群体为基础、面向未来、与他人相连。后来美国人转向**C模式（"冲动性"）自我**——追求个人满足、面向当下、较少受群体束缚。
> - **担忧：** 一个充满自利（甚至自私）、冲动个体的社会，可能不再关心共同善。
> *结对分享：* 做TST并计分，与同学比较。*DIY：* 对3–5人进行小规模试点研究，写一篇3页短文分析回答。

### 群体凝聚力
- **群体凝聚力（Group cohesion）** = 团结感/团队精神；把成员绑在一起的力量。群体生存至少需要最低限度的凝聚力。
- **增强因素：** 共享价值观；共享人口特征（种族、年龄、性别、阶级）；对群体本身的吸引；共同合作达成目标（小圈子、教会会众、绿湾包装工球迷、麋鹿俱乐部）。

#### 群体思维
- **（Irving Janis 1971, 1982）：** 高度凝聚的群体可能要求**绝对一致**并惩罚异议 → 对全体一致的渴望压倒了批判性推理。
- 群体可能觉得自己无懈可击、道德优越；成员压抑疑虑。
- **Lincoln的"对手团队"（team of rivals）** = 解药：顾问足够多元，敢于挑战群体思维。
- **例子：**
  - **NASA挑战者号爆炸（1986）：** 科学家们没有认真对待对发射设计的质疑。
  - **伊拉克战争（2003）：** 参议院情报委员会将夸大WMD证据归咎于群体思维。
  - **2016年大选：** 媒体/民调的群体思维预测Hillary Clinton获胜。
  - **Trump政府：** 异常高的人事更替，用更认同总统观点的人替换异议者（Lu and Yourish 2019）。

| --- | --- | --- |

## 4. 社会影响（同伴压力）

- **社会影响（Social influence）** = 群体对个体决策的影响。我们为了获得**正向制裁（positive sanctions）**（认可）并避免**负向制裁（negative sanctions）**（拒绝）而从众。
- 我们遵循**指令性规范（prescriptions）**（该做的事），并避免**禁止性规范（proscriptions）**（不该做的事）。
- 社会影响影响学业表现、品牌忠诚、受害者责备等方方面面。

### 三种从众（凯尔曼 Kelman 1958）
1. **顺从（Compliance）** —— 最轻微；为了奖励/避免惩罚而随大流；信念不变（被法庭强制参加匿名戒酒会却不认同的人）。
2. **认同（Identification）** —— 为了建立/维持关系而从众；认同该群体并追随其行为（戒酒会参加者开始认同并继续参加）。
3. **内化（Internalization）** —— 最强；把群体信念当作自己的信念；信念与行为合一（戒酒会成员把十二步原则内化为身份与生活方式）。

### 从众实验

#### Asch实验（1951）
- 7–8名"学生"判断线段长度；只有一名是真正的被试；同谋者一致给出错误答案。
- **结果：** 约**33%**是"屈服者"（至少一半次数随大流）；40%较少屈服；只有**25%是"独立者"**，始终拒绝屈服。
- 被试因自己的感知与群体不一致而极度痛苦——有些人以为群体是对的；另一些人明知自己没错，但不想显得与众不同。
- **启示：** 即使证据明确，抵抗同伴压力也很难。

#### Milgram实验（1961–63）
- 灵感来自艾希曼审判和"我只是奉命行事"的辩护。
- 设置："教师"（真正被试）被要求对"学习者"（同谋者）的错误答案施加逐渐升高的电击。
- **结果：** **65%施加到了最高450伏**，尽管听到学习者抗议、撞墙和沉默；只有一人从一开始就拒绝施以低电压。
- **启示：** 普通人常常服从权威，尤其是在觉得自己不用负责的时候。Milgram和同事震惊不已——他们原本预计只有少数人会服从到底。

#### 斯坦福监狱实验（1971）
- **Philip Zimbardo**（Milgram的高中同学）随机指派心理健康的本科生担任"看守"或"囚犯"，在模拟监狱中开展实验。
- 学生迅速进入角色：看守变得残暴；囚犯出现心理创伤；实验在**六天**后被叫停。
- **启示：** **情境动力学（situational dynamics）**，而非个人人格，可以决定行为——角色与权威的力量。

#### 重访Milgram
- 有人认为Asch/Milgram是更强调服从时代的产物；后来的Asch复制实验发现**从众率显著降低**（Perrin and Spencer 1980, 1981; Bond and Sussex 1996）——历史与文化背景会影响表现。
- **Jerry Burger**（2009）设计了符合伦理的Milgram改良复制实验：服从率**仅略低于**原实验 → 权威仍然强烈塑造行为。
- **当代相关：** 阿布格莱布监狱虐囚事件；QAnon和2021年1月6日国会山袭击表明，人们会追随匿名的"权威"做出破坏性行为。

### 💞 关系中的社会学：社交网络——你不是客户，你是产品
- Facebook、Twitter、LinkedIn、Instagram都是美国访问量最高的网站之一；Facebook日活跃用户约15亿。
- **格言：** "当网上的东西免费时，你不是客户，你是产品。"
- **Facebook情绪传染实验（2014）：** Facebook与康奈尔大学调整了约70万名不知情用户的信息流算法，让他们看到略多正面或负面内容；看到快乐内容的用户写出更多积极词汇，看到悲伤内容的用户写出更多消极词汇。
- **伦理风波：** 未经知情同意就拿用户做实验；可能造成情感伤害；Facebook道歉。
- **OkCupid的Christian Rudder**为这类实验辩护："如果你用互联网，你在任何时刻都是数百个实验的对象。"OkCupid把只有30%匹配度的用户告知为90%匹配，发现对话率确实上升。
- **问题：** 把如此多的个人生活权力交给营利性公司，意味着什么？

## 5. 合作共事：团队与领导

### 团队合作
- 早期研究假设群体总是比个体更有效率；后来的研究表明**任务性质与群体特征**都很重要。
- 就总产出而言，群体几乎总是优于单一个体，但与**同样人数各自单独工作**相比，情况就复杂得多。

#### Steiner的潜在生产率 vs. 实际生产率
- **（Ivan Steiner 1972）：** 群体的实际生产率**永远不可能等于潜在生产率**——总会有**过程损耗（process losses）**：
  1. **协调/组织**——决定谁做什么、授权、建立结构（群体越大越严重）。
  2. **社会惰化（Social loafing）**——随着群体规模增大，个体贡献减少，因为个人努力更难被看见。
- **解决办法：** 认可个人努力、让任务更有趣/更有回报、建立强大的**社会认同（Social identity）**（感觉自己代表群体，而不只是成员）。
- **亚马逊的"两个披萨规则"**（Jeff Bezos）：大到两个披萨都喂不饱的团队就太大了——沟通不畅、混乱和官僚主义过多。

### 权力、权威与风格
- **权力（Power）** = 控制他人行动的能力。两种形式：
  - **强制权力（Coercive power）** —— 以武力威胁为后盾。
  - **影响力（Influential power）** —— 以说服为支撑。
- **Max Weber的三种权威类型：**
  1. **传统型权威（Traditional authority）** —— 习俗、出身、神授权利（君主制/王朝）。
  2. **法理型权威（Legal-rational authority）** —— 法律、规则、程序（现代总统制/议会制）。
  3. **魅力型权威（Charismatic authority）** —— 非凡的个人品质；可以打破规则与传统。
  - 类型可以共存（Barack Obama = 法理型 + 魅力型；King Hussein = 传统型 + 魅力型）。
- **领导风格：**
  - **工具型（Instrumental）** —— 以任务/目标为导向（"把事情做完"）。
  - **表达型（Expressive）** —— 以关系/和谐为导向（关注成员情感需求）。
  - **性别化的期待：** 人们期待男性更工具型、女性更表达型。Joe Biden的共情有时被解读为"软弱"；AOC的工具型强势有时被批评为"咄咄逼人"——说明领导风格常被透过性别滤镜评判。

## 6. Bureaucracy

- **科层制（Bureaucracy）** = 一种旨在高效完成任务的特定次级群体——大学、雇主、互联网服务商、快餐店、教会。
- 随着群体变大，它们必然变得更结构化、层级化、科层化。

### Weber关于科层制的六个特征
1. **专业化（Specialization）** —— 分配专门的角色与任务。
2. **技术能力（Technical competence）** —— 成员都经过培训并有资格胜任其角色。
3. **层级制（Hierarchy）** —— 下级受上级管理者和老板监督。
4. **规则与规章（Rules and regulations）** —— 使运作尽可能可预测。
5. **非人格化（Impersonality）** —— 规则先于个人；没有人得到特殊对待。
6. **正式书面沟通（Formal written communication）** —— 备忘录、电子邮件、文件是组织的核心。

- **大学例子：** 教授们几乎不能互相代课；园丁、校警、教练、图书管理员各有专长；从董事会、校长到副校长、教务长、院长、系主任，层级分明；规章制度可能阻止你想做的事；非人格化意味着你被"当作一个编号"对待——因为对学校来说，你就是一个学生ID号。

### 社会的麦当劳化
- **（George Ritzer 1993）：** 科层**理性化（Rationalization）**正从组织蔓延到日常生活——教育、医疗、银行、食品、娱乐。
- **麦当劳模式：** 效率、可计算性、可预测性、通过非人技术实现控制；工人动作被监控；产出标准化。
- **Ritzer的更新（Ritzer and Miles 2019）：** **亚马逊比麦当劳更"麦当劳化"**——取消了实体店、自助购物、员工仅负责仓储和配送。
- **理性的非理性：** 超级理性化系统会产生违背逻辑的结果——肥胖、环境退化、过度消费、工人剥削、强迫性购物。
- **Weber的"铁笼"** = 科层制将个体困在非人性化理性系统中的方式。

### 应对科层制约束
- **科层制不可或缺：** 自来水、电、道路、汽车、保险、食品、衣物、媒体——都由科层组织生产/配送。
- **人性化策略：**
  - **科层制内部的初级关系**——同事庆祝生日、办派对、下班后聚会。
  - **"开明科层制"（enlightened bureaucracies）**——苹果、丰田、谷歌试图包容、分担责任、提供晋升机会。
  - **谷歌的"People Operations"：** 数据驱动的人力资源发现女性入职少（往往由男性面试）、新手妈妈离职率是平均值的两倍；他们改进了招聘流程并延长产假。
  - **改善（Kaizen）**（日本管理技术）：基层员工提出创新改进建议，高层管理者负责落实——富达金融采用。
- **要点：** 企业仍在追求生产力和削减成本，但个体需求与组织需求**不一定相互排斥**。

### 🌍 全球视野：群体规范 vs. 个体规范——荣誉谋杀
- **荣誉谋杀（Honor killing）** = 杀害被认为给家庭/社群带来耻辱的家庭成员（通常是女性）；常见理由：拒绝包办婚姻、身为强奸受害者、穿着/行为不端庄、婚外性行为。
- **与美国案例对照：** Drew Peterson（Drew Peterson）出于个人动机杀害前妻Kathleen Savio（并疑似杀害第四任妻子Stacy）→ 美国人把家庭谋杀视为对家庭忠诚的背叛。
- 在荣誉谋杀文化中，行凶者被视为**规范执行者**而非规范违反者；受害者被视为因羞辱家庭而"该死"。
- **规模：** 联合国估计全球每年多达**5,000名**女性死于荣誉谋杀；研究者认为真实数字更高；仅巴基斯坦每年约**1,000起**（Human Rights Watch 2019）。与社会资源匮乏和性别不平等相关。
- **案例：** **Qandeel Baloch**（2016），巴基斯坦社交媒体明星，被其兄弟下药勒死；兄弟声称她发布"可耻"的Facebook照片给家庭带来耻辱。兄弟最终被定罪并判处终身监禁——这是罕见的判决。
- **启示：** 同一种"家庭忠诚"价值观，让美国人对Peterson感到厌恶，却可能在另一种文化语境中为荣誉谋杀辩护——说明**群体规范如何定义个体行为与道德判断**。

## 7. 结语

- **群体使生活成为可能：** 它们提供生活必需品——食物、衣物、住房、汽车以及我们每天使用的一切。
- **群体使生活愉快：** 陪伴、娱乐、朋友、家庭、娱乐产业。
- **群体也使生活问题重重：** 科层制压制个性；组织造成社会与环境问题；内/外群体动力学滋生冲突与偏见。
- **我们在群体中处于最佳状态，也处于最糟状态。** 群体既能成就伟业，也能犯下暴行。
- **社会学的任务：** 理解群体生活的两个极端以及介于其间的一切。

## 快速记忆钩子
- **群体（Group） ≠ 人群（Crowd） ≠ 类别（Category）：** 群体有**认同 + 持续关系**；人群/聚合体只是共享空间；类别只是共享属性。
- **初级群体（Primary groups） = 情感核心**（家庭、密友）；**次级群体（Secondary groups） = 任务/非人格**（班级、同事）。但真实群体界限模糊。
- **社会网络（Social network）：** 直接纽带 → 间接纽带 → "六度分隔"；**弱关系（weak ties）** = 工作信息；**中心性（centrality）** = 影响力；网络既传播**机会也传播传染**。
- **失范（Anomie） = 规范缺失**（Durkheim）：群体约束太少 → 疏离。Putnam说公民群体在衰退；另一些人说互联网创造了新社群。
- **群体规模（Group size）：** **二人群体（Dyad）**（亲密、不稳定）→ **三人群体（Triad）**（稳定、有调解者）→ 更大 = 更多规则、更少个人化。
- **内群体/外群体（In-group/Out-group）：** "我们 vs. 他们"既产生团结*也*产生偏见；Merton的双重标准——*我们*随和，*他们*懒惰。
- **参照群体（Reference group） = 标尺**；TST：**B模式** = 制度性/群体性自我；**C模式** = 冲动性/个体性自我。
- **群体思维（Groupthink） = 一致性压倒批判性思考**（挑战者号、伊拉克战争、2016媒体）；解药 = "对手团队"。
- **从众阶梯（conformity ladder）：** **顺从（Compliance）**（奖惩）→ **认同（Identification）**（关系）→ **内化（Internalization）**（信念）。
- **经典实验：** Asch（为合群而答错）、Milgram（65%到450伏）、Zimbardo（看守/囚犯）。情境可以压倒人格。
- **免费上网 = 你就是产品** —— Facebook情绪传染实验；OkCupid匹配欺骗。
- **团队（Teamwork）：** 群体优于个体，但永远达不到**潜在生产率（potential productivity）**；**社会惰化（Social loafing）** = 人越多越不出力；**社会认同（Social identity）** = 解药。
- **领导（Leadership）：** **权力（Power）**（强制/影响）+ **权威（Authority）**（传统/法理/魅力）+ **风格**（工具/表达）；领导风格常被性别化评判。
- **科层制（Bureaucracy）（Weber六特征）：** 专业化、技术能力、层级制、规则、非人格化、正式书面沟通。
- **麦当劳化（McDonaldization） = 效率 + 非人性化**；亚马逊是新的麦当劳。
- **荣誉谋杀（Honor killing）**表明**群体规范可以凌驾于个体生命之上**——同一种家庭价值观，在一种文化中是背叛，在另一种文化中却可能是"正义"。
- **归根结底：** 群体使生活可能、愉快、*也*问题重重——社会学帮助我们理解这一切。

# 第2章：研究社会生活——社会学研究方法
## 核心定义（必须牢记）

| 术语 | 定义 |
| --- | --- |
| **定量研究（Quantitative research）** | 把社会生活转化为**数字**、可以按数学方式处理的研究；通常试图寻找因果关系。 |
| **定性研究（Qualitative research）** | 处理**非数值数据**的研究——文本、田野笔记、访谈记录、照片、录音；通常试图理解人们如何理解（建构意义于）自己的世界。 |
| **科学方法（Scientific method）** | 一种获取知识的方法，强调通过观察和实验收集**具体数据**。 |
| **文献综述（Literature review）** | 对某一特定主题相关的已发表研究进行彻底的检索。 |
| **假设（Hypothesis）** | 解释两个或两个以上现象之间关系的理论性陈述。 |
| **变量（Variables）** | 研究者认为相关的两个或更多现象；在实验中被考察。 |
| **操作性定义（Operational definition）** | 对变量做出清晰而精确的定义，以便于对其进行测量。 |
| **可复制性（Replicability）** | 研究能够被重复、从而日后被其他研究者验证的能力。 |
| **相关（Correlation）** | 变量之间的关系，指它们**一起变化**——可能是因果关系，也可能不是。 |
| **因果（Causation）** | 变量之间的关系，指其中一个的变化**直接导致**另一个的变化。 |
| **中介变量（Intervening variable）** | 第三个变量，有时被忽视，却能解释另外两个变量之间的关系。 |
| **虚假相关（Spurious correlation）** | 由**中介变量**造成的看似因果的现象。 |
| **演绎路径（Deductive approach）** | 研究者**先提出假设**，再收集数据来检验它（理论 → 数据）。 |
| **归纳路径（Inductive approach）** | 研究者**先收集数据**，再提出适合数据的理论（数据 → 理论）。 |
| **民族志（Ethnography）** | 一种自然主义的方法，通过在人们**自己的环境中**研究他们，来理解他们赋予自身活动的意义；也指由此产生的文字作品。 |
| **参与观察（Participant observation）** | 与民族志相关的一种方法论，研究者在社会情境中**既是观察者，又成为其中一员**。 |
| **融洽关系（Rapport）** | 一种积极的关系，通常以相互信任或同情为特征。 |
| **田野笔记（Field notes）** | 民族志学者记录的详细笔记，描述其活动与互动；日后成为分析的基础。 |
| **自我民族志（Autoethnography）** | 参与观察的一种形式，**研究者自身的情感与行为**成为研究的焦点。 |
| **厚描（Thick description）** | 在**特定文化语境中**、从其成员视角出发，对互动与意义所做的详细描述（格尔茨 Geertz）。 |
| **反身性（Reflexivity）** | **研究者的身份与活动**如何影响田野环境中发生的一切。 |
| **扎根理论（Grounded theory）** | 一种归纳方法，通过建立范畴并寻找**范畴之间的关系**，从数据中生成理论（格拉泽与斯特劳斯 Glaser & Strauss 1967）。 |
| **代表性（Representativeness）** | 被研究的群体在多大程度上类似于、或代表着更大社会的某一部分。 |
| **效度（Validity）** | 问题/测量工具的**准确性**；研究者测量的是否确实是他们以为自己在测量的东西。 |
| **信度（Reliability）** | 问题/测量工具的**一致性**；同样的问题是否产生相似的答案。 |
| **访谈（Interviews）** | 通过向受访者提问来收集信息的人与人之间的对话。 |
| **受访者（Respondent）** | 研究者试图向其收集信息的研究参与者。 |
| **目标总体（Target population）** | 研究者希望据以进行概括（推广）的整个群体。 |
| **样本（Sample）** | 目标总体中实际将被研究的成员。 |
| **焦点小组（Focus group）** | 同时访谈多名参与者，允许小组成员之间相互互动。 |
| **知情同意（Informed consent）** | 一种保障措施，确保受访者**自愿参与**并了解研究的性质。 |
| **封闭式问题（Closed-ended question）** | 限制了可能的回答范围。 |
| **开放式问题（Open-ended question）** | 允许回答采取受访者选择的任何形式。 |
| **诱导性问题（Leading questions）** | 诱使受访者以某种特定方式作答。 |
| **双管问题（Double-barreled questions）** | 一次**涉及多个问题**；容易得到不完整或令人困惑的回答。 |
| **生命史（Life history）** | 一种访谈方式，要求受访者**按时间顺序叙述**其一生或其中一部分。 |
| **问卷调查（Surveys）** | 向从目标总体中选出的样本受访者发放的问卷。 |
| **李克特量表（Likert scale）** | 一种调查格式，受访者沿**连续谱**选择答案（"非常同意"→"非常不同意"）。 |
| **否定式问题（Negative questions）** | 询问受访者**不**持什么看法，而不是持什么看法。 |
| **预研究（Pilot study）** | 为检验一项更大研究的可行性而进行的小规模研究。 |
| **概率抽样（Probability sampling）** | 任何使用**随机化**的抽样程序。 |
| **简单随机样本（Simple random sample）** | 总体中每个成员被选中的机会**均等**的概率样本。 |
| **回收率（Response rate）** | 完成并返还给研究者的问卷数量/百分比。 |
| **现有资料（Existing sources）** | 因其他目的而生产、但可作为社会研究数据的材料。 |
| **非介入性测量（Unobtrusive measures）** | 依赖现有资料的研究方法；研究者不介入社会情境或其研究对象。 |
| **比较历史研究（Comparative historical research）** | 利用现有资料研究社会各要素在**不同地区与不同时期**之间的关系。 |
| **内容分析（Content analysis）** | 识别并研究出现在文本、图像或媒体信息中的特定**变量或主题**。 |
| **实验（Experiments）** | 对特定变量及其效果的正式检验，在情境的各个方面都可**受控**的条件下进行。 |
| **实验组（Experimental group）** | 接受实验处理的测试组成员。 |
| **对照组（Control group）** | **不接受干预**、以便与实验组比较的测试组成员。 |
| **自变量（Independent variable）** | 被**预期导致变化**的因素。 |
| **因变量（Dependent variable）** | 受自变量影响而**发生变化（或不变化）**的因素。 |
| **基础研究（Basic research）** | **不带有特定议程或实际目的**地追求知识。 |
| **应用研究（Applied research）** | 追求**可用于创造社会变革**的知识。 |
| **偏见（Bias）** | 研究者持有的、可能影响研究或分析的观点。 |
| **客观性（Objectivity）** | 公正性；让**事实自己说话**的能力。 |
| **反应性（Reactivity）** | 人与事件**对"被研究"这一过程做出反应**的倾向。 |
| **霍桑效应（Hawthorne effect）** | 反应性的一个具体例子——预期的效果并非来自自变量，而**来自研究本身**。 |
| **欺骗（Deception）** | 参与者对研究项目或其目标不了解的程度。 |
| **保密性（Confidentiality）** | 保证**除研究者以外的任何人都不会知道**受访者的身份。 |
| **伦理规范（Code of ethics）** | 研究者在设计项目时可供参考的伦理准则。 |
| **机构审查委员会（Institutional review board, IRB）** | 大学内的一群学者，负责审查和批准研究方案并保护人类受试者。 |

## 1. 研究方法概览

- **理论 vs. 方法：** 理论提出假设性主张；**方法则产生数据**，用以支持、反驳或修正这些主张。
- 开头引用了**戴夫·巴里（Dave Barry）的笑话**，说社会学是难以理解的胡言乱语（例如把哭闹的孩子称为"prematurated isolates"）。要点：社会学借鉴了"硬"科学，却常被贬为"软"科学——然而研究完全可以做得清晰、写得清楚。
- **定量研究** —— 数值数据，统计分析（比率、百分比、图表）。*例子：* 2019年，致命车祸中的男性司机有32%的血液酒精浓度 ≥ 0.08%，而女性司机为21%。
- **定性研究** —— 非数值数据（文本、田野笔记、记录稿、视频、照片）；是解释性的而非统计性的分析；关注被研究者视角下的意义。*民族志学者研究过：* 长途卡车司机（Viscelli 2016）、时装模特（Mears 2011）、精英大学里的低收入学生（Jack 2019）。

### 科学方法（参见 [[Science]]）
- **科学方法** = 获取和验证经验性（具体的、科学的）知识的标准程序；构建并检验解释和预测世界的理论。
- 步骤/技能包括：**文献综述 → 假设 → 变量 → 操作性定义 → 可复制性 → 相关与因果 → 演绎/归纳路径。**
  - *相关 ≠ 因果：* 冰激凌销量和溺水人数都在夏季上升（经典的虚假关系）。
  - **中介变量**解释一种看似真实的关系；**虚假相关** = 看起来像真的、但实际上由中介变量造成的因果关系。
  - **演绎：** 先有假设 → 再收集数据来检验它。
  - **归纳：** 先有数据 → 再构建理论来解释数据。
- **托马斯·库恩（Thomas Kuhn, 1962/1970）：** 真理是相对的，取决于人们看待世界的**范式**。范式 = 关于事物如何运作的宽泛理论模型。
  - *例子：* 地心说（以地球为中心）一直居于统治地位，直到**哥白尼（Copernicus, 1543）**提出日心说 → 一场**范式转换（paradigm shift）**，"对先前模型所做假设的重大突破"。
  - 当新数据迫使人们以新的方式看待世界时，范式转换就会发生——**而方法正是产生数据的东西。**

### 该用哪种方法？—— 伍德斯托克（Woodstock）示例
选择方法就是在一套利弊与另一套利弊之间取舍；选择受研究目标、研究者能力、时间、经费以及对受访者的可及性所引导。

| 方法       | 在伍德斯托克的运用                     | 问题                                              |
| -------- | ----------------------------- | ----------------------------------------------- |
| **参与观察** | 在当时（1969年）是理想之选——置身其中，获得第一手数据 | 时机早已过去                                          |
| **访谈**   | 让参与者回忆当年的经历                   | 难以招募（参与者遍布全球），50多年后记忆已衰退                        |
| **问卷调查** | 邮寄/在线问卷                       | 招募仍困难；垃圾邮件式投递；还有**冒充参加过的人**                     |
| **现有资料** | 已出版的第一手记述、影片、照片               | 记述必然是**有选择性的**                                  |
| **实验**   | 重现其核心特征（陌生人的大规模聚集、无官方在场 → 和平） | 伍德斯托克'99"失败了"（火灾、暴力、逮捕）——但实验室可以检验陌生人之间的利他、合作与信任 |

## 2. 民族志 / 参与观察

- 最引人入胜的方法之一；一种以**田野调查**为核心的**定性**方法——在自然发生的社会环境中（"现实世界"）做研究，第一手地研究人们的日常生活。
- **参与观察** = 既是参与者，又是观察者；常与民族志互换使用。
- 涉及**深度沉浸**（数月乃至数年），以形成**成员视角**——从里到外地了解这个社会世界。
- **民族志（ethnography）** 字面意为"书写（graphos）文化（ethnos）"——也指**写成的作品**（通常是一本书）。

### 研究过程
1. **获得进入/接触**田野现场的途径（有些群体难以接近；有些地方不许进入——但社会学家研究的社会世界惊人地多样）。
2. 与研究对象**建立融洽关系**（信任与被接纳）。
3. **收集数据**——主要是日常**田野笔记**；也有一些照片/视频，但观察技能最为关键。
   - **随手记录（jottings）**（简短笔记：关键词、引语、餐巾纸上的涂写、短信）→ 在一天结束时展开充实；有时只能用**"头脑笔记"（head notes）**（仅凭记忆），因为当时无法书写。
4. **分析** —— 寻找模式和主题；把数据归入范畴（"冲突片段"、"共同词汇"）；识别范畴之间的关系 → **扎根理论**（格拉泽与斯特劳斯 Glaser & Strauss 1967）。民族志学者采用**归纳路径**。

### 厚描（克利福德·格尔茨 Clifford Geertz 1973）
- 为传达写得好的田野笔记而提出的概念：不只是照片式的细节——还包括**对语境和互动细节的敏感**（面部表情、语调）。
- 探索某一现象在特定文化情境中的所有可能意义（例如眨一下眼睛）。
- 好的民族志 = 系统、整体，并让读者**从他人的视角**看到这个世界。

### 反身性
- 研究者自身的社会身份（性别、年龄、种族、为人父母）会影响**接近途径**和**所获得的知识**。
- 研究者的**在场会影响**被观察的群体；个人情感（尊敬、轻蔑、好奇、无聊）可能影响观察。对民族志学者尤其重要，因为他们与被研究者关系密切。

### 公开研究 vs. 隐蔽研究
- **公开研究（Overt，更受青睐）：** 公开说明自己的社会学意图——消除了欺骗带来的伦理问题。多数民族志学者采用此法，如 Edin 和 Kefalas。
- **隐蔽研究（Covert）：** 在成员不知情的情况下进行观察。*例子：* **大卫·卡尔维（David Calvey, 2018）**在英国夜总会做了多年保镖，隐瞒了自己的研究者身份（研究保镖的男子气概与身体文化）；目睹了暴力/犯罪行为却未加干预；冒着被揭穿是冒牌货的风险。

### 经典研究：Edin 与 Kefalas ——《我能兑现的承诺》（*Promises I Can Keep*, 2005）
- 研究了新泽西州东卡姆登（East Camden, NJ）的**贫困城市单身母亲**（Edin 举家搬到那里两年半；加入教会、教主日学、做志愿者；Kefalas 在一个针对少女妈妈的 GED 项目里做辅导）。
- 162位黑人、白人和波多黎各裔母亲（平均年龄25岁；单身父母；年收入 <16,000美元）。
- **发现：** 做母亲是一种**稳定剂**，常常是这些女性生活中唯一的积极因素——与主流假设相反。早期养育孩子的感知成本低 + 母职价值高，压倒了其中的困难。
- 作为女性、作为母亲，她们自己有助于建立融洽关系和获得进入途径。

### 优点
1. 细节极其丰富的故事；研究那些故事否则无人讲述的群体——越轨群体（在线上塑造暴力人设的年轻帮派成员——Stuart 2020）*以及*精英群体（维护特权的预科学校学生——Khan 2011）。
2. 挑战理所当然的成见（单身妈妈 ≠ 不负责任）。
3. 可以重塑刻板印象，**并影响社会政策**。
4. 是开创性方法论创新的来源（反身性、研究者角色）。

### 缺点
1. **代表性**问题——小规模研究能否适用于整个社会？（Edin 和 Kefalas 的东卡姆登发现可以说能推广到其他城市的单身母亲。）
2. **耗费资源**（时间、精力、个人投入），且**难以复制**——人、时机、情境、研究者角色的独特组合意味着没人能重复同一研究。民族志学者通过记录方法/角色/关系、共享原始数据（田野笔记摘录）来提高效度。

> **📋 数据工作坊——"观察人们交谈"：** 练习用**厚描**写田野笔记。（1）用5–10分钟*听*一段你看不到的对话（公交车、餐厅）；（2）用5–10分钟*观察*一段你听不到的对话（广场对面）。各写两页以上双倍行距的详细田野笔记，描述参与者、情境以及你认为正在发生的事情。*结对分享（Prep-Pair-Share）：* 标出你能看到/听到的段落（*），圈出评价性词语/概括，标出"想知道更多"的地方（?）。*DIY：* 就田野工作经历写一篇2–3页的短文 + 附上笔记。

## 3. 访谈

- 面对面的、以获取信息为目的的对话，直接从**受访者**那里收集**定性数据**——比电视访谈更系统、更科学。
- 可以单独作为方法，也可以与其他方法结合。**访谈始终由研究者亲自进行**（问卷则可由受访者自行填写）。
- 首先要确定**目标总体**（例如所有有18岁以下子女的父母），然后从中选取一个有**代表性**的**样本**，以便进行概括。
- 访谈项目通常**规模小于**问卷调查；**焦点小组**（5–10名参与者一起接受访谈，允许互动）可以增大样本量。
- 需要**知情同意**——尤其因为大多数访谈都会被录音/录像。

### 问题撰写
- **封闭式**（"你支持还是反对情侣婚前同居？"）vs. **开放式**（"你怎么看待情侣婚前同居？"）。
- 避免：**有偏/诱导性问题**、过于复杂的问题、**双管问题**（一次涉及多个问题）、含糊或煽动性的措辞。
- *例子：* "她的生活有多艰难？"只会引出困难之处；更好的问法："给我讲讲单亲的利与弊。"
- **生命史**方法：按时间顺序叙述受访者的一生。
- 访谈之后，记录被**转写**并分析其中的模式；可以用电脑或人工分类。

### 经典研究：霍克希尔德（Hochschild）——《第二次转变》（*The Second Shift*, 1989）
- 研究双职工家庭的夫妻：下班后家务和育儿由谁来做？
- 访谈了50对夫妻，外加45位参与其家庭安排的人（保姆、日托提供者、教师）。
- 根据家务分工把夫妻**划分为"传统型"、"过渡型"或"平等型"**；量化了做杂务的时间。
- 研究发现在样本之外、对其他地方相似的夫妻也有推广性。

### 现代研究：道恩·玛丽·道（Dawn Marie Dow）——《黑人式育儿》（*Mothering While Black*, 2019）
- 访谈了60位中产/中上阶层黑人母亲，关于如何在育儿中平衡种族与性别议题。
- 核心主题：即使拥有阶级优势，种族也必须进入日常考量——例如，母亲们互相协调，以免自己的孩子成为芭蕾课里"唯一的棕色女孩"；保护孩子（尤其是黑人男孩）免受种族主义之害，同时让他们为之做好准备。

### 优点
1. 受访者**用自己的话说**——揭示无法以其他方式获得的思考、感受和信念（《第二次转变》中的真实写照）。
2. 可以**消除先入之见**，发现被忽视的问题。

### 缺点
1. 有些受访者会有**选择性/自我呈现**——要与其他方法**三角互证**（霍克希尔德观察了一些家庭：实际的家里劳动比夫妻们声称的*更不平等*）。
2. **代表性**问题——样本小；能从50对夫妻推广到一般情况吗？（霍克希尔德把自己的夫妻样本与一项大型全国调查作了比较。）

## 4. 问卷调查

- 向从目标总体中选出的样本发放的问卷。**宏观且定量：** 大规模模式、统计。
- **最早的使用者：** **卡尔·马克思（Karl Marx）** ——1880年代向25,000多名法国工人发放了关于雇主剥削的问卷（对他的写作影响深远）。
- *机构示例：* 罗格斯大学全国婚姻项目（"我们联盟的状况"）；古特马赫研究所（Guttmacher Institute, 2020年5月）：三分之一的美国女性因疫情带来的困难推迟了生育计划。

### 问卷设计
- 大多为**封闭式**；常见格式：**李克特量表**（"非常同意"→"非常不同意"）；有些含"不知道"/"不适用"选项；**开放式填写**问题可提供定性数据。
- 避免**诱导性**、**否定式**和**双管**问题；注意问题**顺序**（较早提到离婚/不忠会左右后面的回答）。
- 先在小群体中**预试**；在大规模发放前进行**预研究**。

### 抽样
- **概率抽样** = 随机化；保证样本无偏、有代表性。
- **简单随机样本** = 每个成员机会均等（就像从帽子里抽名字）。
- **回收率：** 即便约50%的回收率也已算很好；抽样得当的话，20–30%也可作出论断。
- 分析：回答被**编码**为数字；用**SPSS**和**Stata**等软件做统计。
- **在线问卷**（SurveyMonkey）承诺省事省钱，但引发抽样方面的担忧——确保信度、效度和代表性的是*使用者*，而不是软件。

### 优点
1. 最适合为**过于庞大、无法用其他方式研究**的总体收集原始数据；可推广。
2. **快速且经济**；数据量大（在线问卷尤甚）。
3. **信度**强——同样的问题每次产生同类数据。
4. 访谈者/观察者偏见较少；匿名性让受访者在敏感话题上更坦诚。

### 缺点
1. 缺乏**定性深度**（无法对回答做限定；离婚的一个原因可能既是经济上的*又是*情感上的）。
2. **效度**较弱——自我报告不总是诚实的（对离婚感到羞耻）。
3. 自我选择带来**抽样问题**（对家暴支持团体做调查 → "发生率"100%）；在线调查更糟。
4. 可能被用来**制造论断/推行议程**，而非用于科学（某SUV厂商的"90%的家庭想要更大的车"）。

> **📋 数据工作坊——"媒体使用模式"：** 美国人平均每天花约11小时在电子媒体上（Nielsen 2018）。设计并实施你自己关于媒体使用的调查：（1）决定研究什么，（2）从目标总体中选取样本，（3）撰写/排版问卷，（4）实施调查，（5）分析并展示结果。*结对分享：* 小组共同设计项目并做预试。*DIY：* 调查5–8人；写一篇3–4页关于过程和初步发现的短文；附上问卷。

## 5. 现有资料

- 几乎取之不尽的数据已经存在：**档案/历史记录**（结婚证、建筑许可证）、**媒体**（书籍、杂志、电视节目、网站）。
- 被视为**非介入性测量**——不打扰、不干扰被研究的人。
- 具体路径：
  - **社会人口学（Social demography）** —— 人口规模、构成、增长、分布（数据来自政府机构；**美国人口普查局（U.S. Census Bureau）**在Census.gov免费提供数据）。
  - **"社会考古学"（"Social archaeology"）** —— 在社会环境里挖掘（普通美国人每天扔掉2磅多垃圾……垃圾能揭示什么？）。
  - **比较历史研究** —— 跨地区、跨时期研究社会各要素之间的关系（文学、绘画、报纸、照片）。
  - **内容分析** —— 统计/识别文本、图像、媒体中反复出现的主题或特定变量（词语、视觉元素）；分析它们之间的关系。

### 经典研究：斯特恩斯（Stearns）——《焦虑的父母》（*Anxious Parents*, 2004）
- 利用育儿手册、报纸、期刊，研究19–20世纪童年含义的变迁。
- 儿童从**自给自足的"小大人"**（其劳动力曾被需要）变为需要保护的**脆弱存在**——要防范小儿麻痹症、蛀牙、绑架者、"乱飞的躲避球"、天真不再……
- 日益增长的父母愧疚/焦虑 → 可能预示了今天的**"直升机父母"**。

### 内容分析研究：萨布丽娜·斯特林斯（Sabrina Strings, 2019）
- 分析了18世纪的报纸、杂志、视觉艺术以及关于黑人女性身体的科学/医学文献。
- **发现：** 当代的瘦身理想——以及瘦与健康的关联——**植根于反黑（anti-Blackness）**；对肥胖的恐惧可追溯到启蒙时代"肥胖 = 种族低劣/野蛮"的观念。肥胖恐惧既是**种族化的，也是性别化的**。

### 优点
1. 能获取研究者自己永远无法收集的信息（美国人口普查）；数据可以在研究者之间**汇集/共享**。
2. 能进入**不同时期**的社会世界（19世纪初边疆妻子的书信/日记——Peavy & Smith 1998）。
3. 同一份数据可以**复制以往的项目**——检验信度、追踪随时间的变化。

### 缺点
1. 原始作者并没有想着你的问题（他们的信里没有明确提到边疆女性的性生活）。
2. 内容分析描述的是信息本身，而**不是它们如何被解读**（电视中的女性角色地位较低——但这给观众带来什么影响，还需要更多研究）。

## 6. 实验方法

- 最接近经典的**科学方法**；用于群体权力动态、种族歧视、性别社会化等研究——在实验室、公司董事会，甚至街角。
- 两个基本目标：（1）开发**精密的工具**来观察/记录/测量；（2）**控制除所研究变量之外的所有变量**。
- 设置：把相似的受试者随机分入**实验组**（接受处理）和**对照组**（不接受）。处理 = **自变量**；结果 = **因变量**。
- 数据分析倾向于**定量**（分离出一个变量并测量其效果）。

### 经典研究：索恩（Thorne, 1993）—— 粉色/蓝色婴儿实验
- 成年人玩的是*同一个*婴儿，只是穿着粉色或蓝色；受试者从衣服颜色推断性别：
  - "男孩"（蓝色）：抱得没那么轻柔，声音更响亮——"你真是个大个子壮男孩！"
  - "女孩"（粉色）：抱得更近，轻声细语——"多可爱的小姑娘！"
- **结论：** 性别社会化从婴儿期就开始了；性别从很小的时候起就塑造着知觉和互动。

### 歧视研究
- 资历相同、只在种族/性别上有差异的求职者去应聘、申请房贷等（Pager 2007; Hanson et al. 2016; Quadlin 2018）：**白人和男性获得更好的工作/房贷条件；女性和少数族裔得到较差待遇或一无所获**——尽管资历完全相同。

### 优点
1. **操纵和控制**社会环境；外部干扰最小；可以精确挑选参与者。
2. **确立因果关系的最佳方法** —— 例如识别**"母职惩罚"（motherhood penalty）**（Correll, Benard & Paik 2007：在职母亲薪酬更低、晋升更少；父亲反而获得回报）。
3. **可复制性** —— 可以重复进行，以衡量历史/文化变迁。⚠️ 但存在**"可复制性危机"**：近年尝试复现有影响力的实验研究（尤其是心理学的）屡屡失败——原因是社会环境的改变、有问题的抽样、伦理约束。

### 缺点
1. 只适用于能在**受控环境中**构建和测量的研究——实验室是人为的；结果在混乱的现实世界中未必成立。补救：**田野实验**（例如班级规模效果——Baldassarri & Abascal 2017）。
2. 通常依赖某种程度的**欺骗** → 需要严格的伦理准则、**参与后的说明（debriefing）**（解释实验并处理欺骗带来的影响）。著名的激烈案例：**米尔格拉姆的服从实验；斯坦福监狱实验。**

## 7. 社会网络分析（SNA）

- 一种**测量和可视化人与人之间社会关系结构**的工具。
- 方法：问卷询问受访者遇到问题会向谁求助（信息、建议、支持）→ 绘制网络图。
- 用于青少年风险行为、信息扩散、企业行为等研究（Abrutyn & Mueller 2014; Pedulla & Pager 2019）。

### 如何解读网络图（图2.2：六年级学生的友谊）
- 圆点 = 学生（红色女孩、蓝色男孩）；**箭头** = 社会联系；箭头越多 = 越"核心"/受欢迎。
- **桥（Bridges）** = 连接不同群体/小圈子的学生（信息经由他们流动）。
- 在示例中：女孩的朋友几乎全是女孩，男孩亦然；只有女孩把男孩列为朋友（**联系缺乏互惠——箭头单向流动**）；每个人都通过约3步相连（分隔度）。

### 历史
- **格奥尔格·齐美尔（Georg Simmel，20世纪初）：** 社会联系以及**群体规模**如何影响成员间的关系——SNA早于互联网。
- **斯坦利·米尔格拉姆（Stanley Milgram，1960年代末）：** "小世界"现象——每个人都通过平均**5.5–6步**相连 → **"六度分隔"**（Travers & Milgram 1969）。
- 计算机程序使SNA成为一个庞大而多元的跨学科领域；如今它绘制**Instagram、Facebook、Twitter、Snapchat、LinkedIn**的网络——例如研究恐怖分子的沟通模式（Everton 2012）、占领华尔街运动在Twitter上的组织动员（Tremayne 2014）、以及**新冠（Covid-19）**的传播（Weeden & Cornwell 2020）。

### 优点
1. 能追踪任何东西——思想、疾病、谣言、潮流——在群体/社区中的传播路径；对**流行病学家、政治社会学家、市场研究者**都很有用。
2. 常使用**"大数据"**（大到常规程序无法处理的数据集）——使企业能发现趋势、瞄准受众；催生新的研究领域。

### 缺点
1. 往往是定量的 → 可能**忽视社会行动者经验的细节与多样性**；要与定性方法结合（**混合方法**）——例如**马里奥·斯莫尔（Mario Small）**，《意料之外的收获》（*Unanticipated Gains*, 2019），描绘了托儿中心对纽约市家庭社交网络的影响。
2. **大数据很贵**，而且大数据集常常来自为其他目的（如广告）而汇编的数据源，或**带来隐私威胁**。

## 8. 面向未来：新兴方法

### 行动研究（Action research）—— 把研究与社会变革结合起来
- 把社会科学研究与**社区问题解决和社会变革**相结合；对社会学关于伦理、偏见和研究者角色的既有信念提出质疑。
- 是与人一起研究，而不是研究人——研究对象是积极、协作、平等的参与者（"参与型学术"，Rajaram 2007）。
- *例子：* 芝加哥的**COFI** —— "约翰尼为什么没上幼儿园？"受过访谈培训的社区成员与5,000多名家长交谈，了解入园的障碍 → 设计外展宣传活动 → **目标社区的入园率提高了**（COFI 2009）。

### "网志"（Netnography，网络民族志）
- 把参与观察的方法应用于**在线社区**（游戏环境、社交媒体、网络空间）；是改编现实世界的民族志方法，而非发明新方法。
- *例子：* 不孕不育（Lee 2017）、处方药使用（Del Fresno & Peláez 2014）；**布丽吉特·博姆（Brigitte Borm, 2017）**研究了Airbnb房东的线上讨论，以及把房子租给陌生人后他们对"家"的定义如何改变。

### GIS（地理信息系统）
- 把社会科学数据附加到**地理位置**上的计算机软件——不仅知道某市有13%的人生活在贫困中，还知道*在哪里*。
- 把疾病地图叠加在污染物暴露地图上；研究疾病、让服务匹配人口、研究移民（Sianko & Small 2017）；被广泛用于理解**新冠**（Franch-Pardo et al. 2020; Kuchler et al. 2021——Facebook数据显示与早期热点有联系的地方病例更多）。
- *例子：* **Oakley & Burchfield（2009）**绘制了芝加哥公共住房居民在拆除-搬迁前后的地图：被搬迁的居民未必落到"更好的"社区——"通过搬迁逃离高贫困社区的希望非常渺茫"（第606页）。

## 9. 社会学研究中的议题

### A. 研究方法的非学术用途
- **美国人口普查局：** 自**1790年**起每10年普查一次总人口；为政府决策提供依据（学校、医院、红绿灯）。
- **民意调查：** 盖洛普（Gallup）、佐格比（Zogby）、罗珀（Roper）——民调不仅反映民意，还能**塑造**民意；要弄清是谁委托了这项民调、他们是否有议程。
- **商业：** 民族志学者研究组织文化；实验/团队游戏揭示任务导向的网络如何形成、领导者如何涌现、合作如何发展。
  - **雪莱·科雷尔（Shelley Correll）** 通过实验识别了"母职惩罚" → 如今设计**多元化、公平与包容（D&I）**干预方案（2017）。
- **市场研究：** 最常见的非学术用途——一个数十亿美元的产业。点击Cookie、弹窗点"是"、《与星共舞》的投票 = 数据。⚠️ 很少有市场研究达到严格的科学标准；底线是卖东西。

### B. 价值观、客观性与反应性
**价值观：**
- **马克斯·韦伯（Max Weber, 1925/1946）** —— 《以科学为业》（"Science as a Vocation"）：提出**"价值中立"（value-free）社会学**——把事实与个人价值观分开。
- 挑战：马克思主义者把研究与**实践（praxis，社会行动）**相结合；符号互动论者如**大卫·马扎（David Matza, 1969）**认为，恰恰是改变世界的意图妨碍了理解世界。
- 争论：**基础研究**（为知识而知识）vs. **应用研究**（把知识付诸行动）。
- **偏见**可能渗透到每个阶段——从选题、抽样，到问题措辞、分析、写作。
  - *有争议的例子：* **马克·雷格内鲁斯（Mark Regnerus）的"新家庭结构调查"（2012）**——发现同性恋/女同性恋父母的孩子结局"欠佳"；批评者指出：经费来自保守派/宗教基金会、评审人不合格、把所有同性关系混为一谈、把从未与同性恋父母生活过的孩子也算进去、没有把家庭结构与稳定性分开、以及选择在最高法院"法庭之友"意见书提交之际发表。这引发了宗教价值观如何影响研究和政策的思考。

**客观性：**
- 从**孔德（Comte）**以来的理想：理性而客观地研究社会；事实应当自己说话。
- 但"事实"是会出错的——种族主义、性别主义、民族中心主义的视角长期以来被当作"真理"（科学现实 = 白人欧洲男性的经验）。
  - *例子：* 女性的心脏病长期得不到诊断，因为医学研究主要使用男性受试者——女性的症状不同（Criado-Perez 2019）。
- 主观性是不可避免的——而且有些人（自我民族志学者、后现代思想家、混沌理论/模糊逻辑）质疑客观现实是否根本存在。

**反应性（霍桑效应）：**
- **埃尔顿·梅奥（Elton Mayo, 1949），** 芝加哥西部电气公司霍桑工厂（1927–1932）：每一次改变照明、工间休息，甚至薪酬 → 生产率都在*上升*；恢复到原始条件 → 生产率*再次*上升。
- 结论：被操纵的变量不是原因——**"被研究"这一效应本身才是**。受试者会对研究者的关注做出回应，可能会"给他想要的"。

### C. 研究伦理
- 社会研究的风险是微妙的（与药物试验相比）：研究者常常不把项目完全讲清楚；民族志学者在某种程度的保密状态下工作；**隐蔽研究**使所有互动都变得不真实。
- 伦理规范规定的是**原则**，而非严格规则：寻求**知情同意**；保护受试者免受**伤害**。
- 最大的伤害 = **泄露保密信息**。受试者有权享有**"传记匿名权"（rights of biographical anonymity）**——对脆弱人群（儿童、无证移民、精神病患者）和有争议的话题尤为关键。
  - *化名的失败：* **林德夫妇（Lynd & Lynd）的"米德尔敦"（Middletown）**（1929/1959, 1937）后来被揭露就是**印第安纳州的曼西（Muncie）**——对其名声不利。
  - **卡罗琳·埃利斯（Carolyn Ellis, 1995, 2007）：** 她渔村田野点的村民对她书中对他们的描写感到不安；觉得被背叛了；拒绝再和她说话——她被一个自己曾融入其中的社会世界拒之门外。
  - **爱丽丝·戈夫曼（Alice Goffman）——《逃亡中》（*On the Run*, 2014）：** 对费城年轻黑人男性的民族志研究（6年）；备受赞誉但也充满争议——再现的政治（一位享有特权的白人女性能否替被边缘化的黑人男性发声？）；一份匿名的60页批评指控其记述前后不一致（戈夫曼的说法：这是保护消息源匿名的结果）。

### 🌍 全球视角：《纽伦堡法典》与塔斯基吉
- **《纽伦堡法典》（Nuremberg Code）**（二战后审判；纳粹医生因在集中营囚犯身上做实验受审；23人中有16人被定罪）：由医生**安德鲁·艾维（Andrew Ivy）与利奥·亚历山大（Leo Alexander）**起草的准则——研究只能为"造福社会的富有成效的结果"，保护受试者免受"一切不必要的身体和精神痛苦与伤害"，而且只允许**知情的、非强迫的同意**。
- 与此同时，美国犯下了自己的暴行：**塔斯基吉梅毒研究（Tuskegee Syphilis Study, 1932–1972）**：399名阿拉巴马州贫困黑人男性在梅毒未得到治疗的情况下被观察，以研究疾病的自然进程——即使在1947年青霉素成为标准疗法之后依然如此。1972年曝光；**1997年比尔·克林顿总统正式道歉**。
- 教训：所有科学研究——无论是社会的还是医学的——都必须遵守伦理标准。
- **美国社会学协会（ASA）伦理规范：** 避免偏见、遵循专业标准、保护受访者。
- **IRB（机构审查委员会）：** 审查研究方案的大学团体；可以要求修改或叫停项目；经费可能被撤销。⚠️ 争议：委员会往往全是医学/自然科学家——他们能评判社会研究吗？有人主张**分学科审查**（由社会学家评审社会学家）。

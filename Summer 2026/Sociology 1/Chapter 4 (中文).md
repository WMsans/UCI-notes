# 第4章：社会化、互动与自我
## 核心定义（必须牢记）

| 术语 | 定义 |
| --- | --- |
| **社会化（Socialization）** | **学习并内化我们所属社会群体的价值观、信念与规范**的过程，借此我们成为社会的正常成员。这是一个*双向*过程：社会教导个体成为正常成员，**同时**个体学习/内化群体的价值观与规范。 |
| **天性 vs. 教养之争（Nature vs. nurture debate）** | 关于**遗传（天性）与社会化（教养）**在决定个体行为与特质方面各自作用的持续讨论。 |
| **社会生物学（Sociobiology）** | 运用**生物学与进化论来解释社会行为**的学科分支（E. O. 威尔逊 Wilson 1975）。 |
| **野孩（Feral children）** | 在神话和罕见的现实案例中，从小**很少与人接触**、可能在年幼时就与社会隔绝的儿童（与莫格利 Mowgli 那样的"人猿小孩"虚构故事相对照）。 |
| **自我（Self）** | 个体对**与他人相分离、相区别的个人身份的自觉的、反身性的体验**——我们能够把自己当作"不止一个存在"来思考，并能从旁观者的视角看待自己。 |
| **本我（Id）** | （弗洛伊德）由**基本先天驱力**构成的心灵部分，是本能心理能量的来源；自私而不切实际，追求**快乐并回避痛苦**。 |
| **自我（Ego）** | （弗洛伊德）**心灵中现实的一面**，在本我与超我的力量之间起平衡作用；按理性运作，协调/整合二者的要求。 |
| **超我（Superego）** | （弗洛伊德）代表**内化了的社会要求**；由两部分组成——**良心（conscience）**（使我们不做社会所不容的行为）和**自我理想（ego-ideal）**（维系我们"应当成为什么样的人"的理想愿景）；通过父母的奖惩而发展。 |
| **心理性欲发展阶段（Psychosexual stages of development）** | （弗洛伊德）从出生到成年之间自我发展的**四个不同阶段**；人格怪癖源于在某一阶段**固着（fixated）**（卡住）而未能前行。 |
| **镜中自我（Looking-glass self）** | （库利）自我通过**我们对自己所感知到的、他人对我们的评价与评判**而发展——"每个人都是一面镜子，/映照着从旁经过的他人。" |
| **预备阶段（Preparatory stage）** | （米德）自我发展的**第一阶段**，儿童在**不完全理解含义的情况下模仿或仿效他人**（约3岁以下）。 |
| **游戏阶段（Play stage）** | （米德）**第二阶段**，儿童假装扮演**特定他人或重要他人**的角色（扮演"妈妈"、"消防员"、"医生"）。 |
| **特定他人或重要他人（Particular or significant other）** | 儿童学习并内化的**某一特定角色**的观点与期望。 |
| **博弈阶段（Game stage）** | （米德）**第三阶段**，儿童参与有组织的游戏，并采纳**概化他人**的视角（小学早期）。 |
| **概化他人（Generalized other）** | **他人网络（或整个社会）**的观点与期望，儿童学习后在塑造自身行为时加以考虑。 |
| **自我的双重性（Dual nature of the self）** | （米德）我们把自我同时体验为主体和客体的观念——**"主我"（"I"）**（自发的、主动的、有创造力的、较少社会化的）与**"客我"（"me"）**（遵守规范的、顺从的、更社会化的、依赖他人的）。 |
| **托马斯定理（Thomas theorem）** | "如果人们**把情境定义为真实的，它们在其后果中就是真实的**"（托马斯与托马斯 Thomas and Thomas 1928）——我们定义每种情境的方式即成为它的现实。 |
| **情境定义（Definition of the situation）** | 与他人就某一情境中"**正在发生什么**"达成的一致；这种共识使我们能够与他人协调行动、实现目标。 |
| **行为表达（Expressions of behavior）** | 诸如翻白眼或点头之类的小动作，作为**互动工具**把我们对该情境的定义传达给他人。 |
| **给予的表达（Expressions given）** | **有意的、通常是言语的**表达，如话语（我们大部分言语）。 |
| **流露的表达（Expressions given off）** | **可能有意图、也可能无意**的、通常**非言语**的可观察表达（面部表情、举止习惯、身体语言、衣着打扮）。 |
| **印象管理（Impression management）** | 努力**控制我们给他人留下的印象**，使他们形成我们所期望的、关于我们和情境的看法；运用自我呈现与表演策略。 |
| **拟剧论（Dramaturgy）** | （戈夫曼）一种从**社会生活与戏剧表演的相似性**出发分析社会生活的方法。 |
| **前台（Front）** | 在拟剧视角中，帮助确立情境定义的**表演场景/舞台**（教学的教室、喝酒的酒吧）。 |
| **区域（Region）** | 表演发生的环境，包括**地点、布景、装饰与道具**。 |
| **个人前台（Personal front）** | 我们用来向他人呈现自己的表演策略，包括**外貌、服饰与举止**（加上性别、种族、年龄）。 |
| **后台/后区（Backstage / back region）** | 我们**排练和准备**表演的地方。 |
| **前台/前区（Frontstage / front region）** | 我们**向他人观众交付表演**的地方。 |
| **社会建构（Social construction）** | 一个概念或做法由参与者**集体认定其存在**、从而被创造和维系的过程（伯格与卢克曼 Berger and Luckmann 1966）。 |
| **冷却"受骗者"（Cooling the mark out）** | （戈夫曼）帮助他人**保全面子或避免难堪**的行为——常被称为礼貌或得体（借自骗局行话）。 |
| **社会化主体（Agents of socialization）** | 提供社会化得以发生的结构化情境的**社会群体、制度与个人——尤其是家庭、学校、同伴与媒体**。 |
| **隐性课程（Hidden curriculum）** | 学生在整个求学过程中**间接**学到的价值观或行为（守时、整洁、守纪、勤奋、竞争、服从，以及阶级/种族/性别意识形态；杰克逊 Jackson 1968）。 |
| **再社会化（Resocialization）** | 在人生转折中**用新学会的规范与价值观取代先前所学**的过程。 |
| **全控机构（Total institutions）** | （戈夫曼 1961）使个体**与社会其他部分隔绝**、以便对其加以控制和规训的机构，其目的是系统地剥离先前的角色与身份，以便创造新的身份（监狱、邪教、精神病院、寄宿学校、养老院、修道院、军队）。 |
| **地位（Status）** | **社会等级中的某个位置**，承载着一整套特定的期望。 |
| **先赋地位（Ascribed status）** | **与生俱来**的地位；通常难以或无法改变（性别、种族）。 |
| **具身地位（Embodied status）** | 由**生理特征产生**的地位（美貌、残障）。 |
| **自致地位（Achieved status）** | 通过**个人努力赢得的**地位（职业、爱好、技能），或由他人强加的（罪犯身份、精神疾病、吸毒成瘾）。 |
| **主地位（Master status）** | 在我们的身份中**似乎压倒其他一切**的地位；始终相关，并影响我们所拥有的所有其他地位（例如对女性、亚洲人、医生、酒鬼的假定）。 |
| **刻板印象（Stereotyping）** | 基于对人群**群体或类别的先入之见、以概化方式**评判他人。 |
| **角色（Role）** | 因某人的地位而**期望他做出的一整套行为**；提供一份"剧本"（戈夫曼 1956；特纳 Turner 1978）。 |
| **角色冲突（Role conflict）** | 当我们**同时占据两个或更多、期望相互矛盾的角色**时体验到（参议员 vs. 母亲）。 |
| **角色紧张（Role strain）** | 当**同一角色内部存在相互矛盾的期望**时体验到（父母必须陪伴*又*要养家糊口）。 |
| **角色退出（Role exit）** | **离开一个我们不再占据的角色**的过程。 |
| **角色采择情感（Role-taking emotions）** | 诸如**同情、尴尬或羞耻**之类的情感，要求我们采纳另一个人或群体的视角并相应地做出回应。 |
| **情感规则（Feeling rules）** | （霍克希尔德 1975）**关于情感表达与显露的社会建构规范**——在特定情境下对"可接受/合意感受"的期望（"男孩不哭"、"葬礼上不许笑"）。 |
| **情感劳动（Emotional labor）** | （霍克希尔德 1983）**唤起、压抑或以其他方式管理感受**以创造出公开可观察的情感表露的过程（空乘人员、服务员、优步司机）。 |
| **共同在场（Copresence）** | **面对面互动**或与他人在场共处。 |
| **饱和自我（Saturated self）** | （格尔根 1991）一种后现代观念：自我如今由**从广泛媒体来源中挑选出的多重影响**所塑造——形成一种"拼贴人格（pastiche personality）"，从任何可得的来源借用身份的零零碎碎。 |
| **能动性（Agency）** | **个体自由、独立行事的能力**；我们是自发的、明智的、有创造力的——不仅仅是社会化的被动接受者。 |

## 📍 章节开篇：Finsta、Rinsta 与精心策划的自我

- Instagram 已成为**呈现自我**的主要手段——一个账号就是对*你是谁*的一种主张；一种记录和展示"所有正确时刻"的隐晦要求（策展、裁剪、滤镜、配文、话题标签；常发但不要发太多）。
- **Rinsta（"真实 Instagram"）：** 经过筛选、公开、精心策划的自我，是你希望别人看到的那个自己。
- **Finsta（"虚假 Instagram"）：** 私密、上锁的次级账号，经过仔细筛选、关注人数极少（只有最亲近的朋友/家人）。一个可以自然表现的"安全之地"——不讨喜的自拍、搞笑帖、圈内梗。
- **悖论：** 在 finsta 上，人们可能比在 rinsta 上*更不虚假、更真实*。
- **本章的问题：** 什么是你的"真实自我"？自我意识从何而来？
- **预览：** 自我**在很大程度上是社会产物**——通过社会互动被创造和改造。（与后文"在线互动"部分以及[[Chapter 3]]"文化作为透镜"的观点相呼应。）

> **启示：** 社交媒体使**印象管理**（戈夫曼）的日常劳作变得可见——我们在不同场合呈现不同的自我，并寻求他人的认可。

## 1. 什么是人性？

- **"这就是人性"**常被用来解释从暴力、嫉妒到爱与利他的一切——但从社会学视角看，**文化与社会的存在才是使我们成为人的东西**。我们赋予食物、住房、性以及其他一切的意义都是*学来的*——社会就是老师。
- 如果你出生在14世纪的日本、一个阿兹特克农民家庭或挪威王室，你会是一个截然不同的人：不同的语言、技能、意义和自我感。（阿兹特克农家女孩15岁未婚就会被视为"老姑娘"；McCaa 1994。）

### 天性 vs. 教养之争
- **天性派**（社会生物学家、部分心理学家、自然科学家）：行为特质由**遗传**解释。
- **教养派**（社会学家、社会科学家）：人类行为是**通过社会互动习得和塑造的**。
- **两派都对：**
  - 睾酮有助于"男性化"特质（攻击性、好胜心）——*但*面对竞争性挑战也会**提高**睾酮水平。哪个是因，哪个是果？
  - **安德森等人（Anderson et al. 1999）：** 前额叶皮层受损的患者——如果在**婴儿期**受伤，在道德/社会推理上有困难；如果在**成年后**受伤，则能应付自如。→ 大脑发育中存在一个**关键期**，道德推理能力在其中习得。天性提供了一个*生物窗口*，社会与道德发展经由它发生。
- **要点：** 遗传提供基本**潜能**；我们的社会环境决定我们是实现还是辜负这种潜能。社会影响从出生时（或更早）开始，随岁月增长——因为如此渐进且无意识，我们根本注意不到自己在学什么、怎么学的。

### 📡 未来之窗：遗传学与社会学
- **2003年人类基因组计划**识别了构成人类DNA的全部基因。遗传学家发现**社会环境实际上可以改变基因**→ 与社会学的兴趣交汇。
- **社会生物学**（自1975年起就备受争议）：**爱德华·O. 威尔逊（Edward O. Wilson）**的《社会生物学：新综合》（*Sociobiology: The New Synthesis*）坚定地站在**天性**一边（遗传决定论）→ 遭到社会学家猛烈批评。威尔逊的《论人性》（*On Human Nature*, 1978）："人类行为差异的相当大一部分基于遗传差异。"
- **《钟形曲线》（The Bell Curve）**（赫恩斯坦与默里 Herrnstein and Murray 1994）——提出*因种族而异的IQ遗传基础* → 激烈的争议；误导性的媒体报道；社会生物学失宠。
- **今天："社会基因组学"（social genomics）/ "社会基因学"（sociogenomics）**（康利与弗莱彻 Conley and Fletcher 2017；布利斯 Bliss 2018；米尔斯与特罗普夫 Mills and Tropf 2020）——新一代把遗传学与社会学结合起来：**基因受社会经验调节，与*社会/文化因素协同*起作用，而非独立运作**。
  - **莫莉·马丁（Molly Martin, 2008）：** 利用双胞胎/同胞/同母异父（同父异母）兄弟姐妹的数据，亲子体重关联不仅源于共享基因，**还源于共享的生活方式**——社会因素（不吃饭、看电视/打游戏的时间）与父母肥胖同样有影响。
  - 教育成就、冒险行为、酗酒、肥胖 = 遗传 + 社会因素的复杂互动。
- 康利与弗莱彻（2017）："遗传学革命也许早已如火如荼，但**社会基因组学革命才刚刚开始**。"

### 社会隔离
- **克里斯托弗·奈特（Christopher Knight）——"北塘隐士"（North Pond hermit）**（缅因州）：在林中隐居27年不被人发现（约1980年代中期至2013年，从20岁到47岁）；只与一个人说过话；犯下1,000多起入室盗窃；从未被抓获。谈及隔离：*"没有观众，没有人为之表演，我就只是在那儿。我没有必要定义自己；我变得无关紧要……我甚至没有名字。我从未感到孤独。"* → 身份需要观众；自我通过互动建构。
- **野孩**——让社会科学家得以研究隔离影响的罕见案例（戴维斯 Davis 1940, 1947；牛顿 Newton 2004）。婴儿有先天能力，但只有**通过与他人的接触**才能充分发展。
  - **吉妮（Genie, 1970，加州阿卡迪亚）：** 13岁时被发现；从小被锁在一间小屋里，常常被绑在便盆椅/婴儿床上，几乎被剥夺了所有人类互动和语言；缺乏言语和身体发育；抓人、嗅东西、吐口水。一个科学家团队研究并治疗她——手语和社交技能进步迅速——但团队分裂、经费被撤，她在寄养家庭遭受进一步虐待，丧失了大量言语能力；1978年结案。**此类研究的伦理至今仍有争议。**
  - **特平一家（Turpin family, 2018，加州）：** 13名儿童被囚禁多年，每天被铐在床上约20小时，遭受殴打/折磨；身体发育迟缓，缺乏认知技能和对外部世界的基本了解。
- **结论：** 极端社会隔离具有毁灭性；只有通过与他人的接触，我们才能发展出我们视为"自然而正常"的品质。
- 社会化始于婴儿期，一旦孩子理解并使用语言便尤其高效（奥克斯 Ochs 1986）——但它是**终身的**：学校、工作、婚姻、为人父母等等。

## 2. 社会化的过程

- 与朋友"社交"只是社会学家所指含义的一部分：**社会化是一个双向过程**——（1）社会/文化/群体**教导**个体成为正常成员；（2）个体**学习并内化**群体的价值观与规范。
- 它同时作用于**个体层面和社会层面**：我们学习所在社会的生活方式，并把它变成自己的。
- **两大目标：**
  1. 教会成员满足基本人类需求和抵御危险所必需的**技能** → 确保社会继续存在。
  2. 传授文化的**规范、价值观与信念**，并提供确保成员遵循共同生活方式的方法。
- 与[[Chapter 3]]相呼应：社会化是文化（价值观、规范、语言）得以传递和内化的方式。

## 3. 自我理论

- 笛卡尔：**"我思故我在"**——我们拥有关于自身的意识；意识是人之为人的核心。
- **自我** = 我们体验到的、与他人截然不同的、真实独立的个人身份。我们可以"为自己骄傲"、"失去自制"、"改变自己"——我们把自己当作"不止一个存在"来思考，并能从旁观者的视角看待自己。
- 社会学家相信，自我在人的一生中**通过社会互动被创造和改造**——但关于*如何*发生，有若干种理论。

### A. 精神分析理论：西格蒙德·弗洛伊德
- 强调**童年与性发展**是对身份不可磨灭的影响；社会通过人类本能的转化得以维系。
- **无意识心灵**（《梦的解析》，1900/1955）：意识觉察只是*冰山一角*；水面之下是前意识和无意识。**无意识能量是有意识思想和行为的来源**（无意识中除掉对手的冲动 → 有意识决定比竞争同事更努力工作）。
- **心灵三个相互关联的系统：**
  - **本我（Id）** —— 生物驱力；本能心理能量的来源；追求**快乐、回避痛苦**；自私而不切实际（"偷懒，喝两杯"）。
  - **自我（Ego）** —— 处理**现实世界**；按理性运作；协调/整合本我与超我（"如果我继续努力，我一定能升职"）。
  - **超我（Superego）** —— **内化了的社会要求**；两部分：**良心（conscience）**（阻止社会所不容的行为）和**自我理想（ego-ideal）**（我们"应当成为什么样的人"的理想愿景）；由父母的奖惩发展而来；抑制本我，引导自我走向道德上可接受的行为。
- **四个心理性欲阶段**（婴儿期至成年之间；弗洛伊德 1905）：每一阶段与不同的**性感区**相关联；前三个阶段发生在1–5岁之间，为成年生活"奠定基础"（对这段时期几乎没有记忆）；最后阶段约12岁开始，很少有人完整经历。在某一阶段**"固着"**→ 成年后的心结："口欲期固着"（吸烟、暴食、言语攻击）、"肛门期固着"（洁癖、吝啬鬼、控制狂）。
- **《文明及其不满》（Civilization and Its Discontents, 1930/2010）**：个体心理有助于创造**社会秩序**——我们必须把潜意识驱力（性、攻击性）导入社会可接受的渠道：性欲能量 → 创造性追求（文化、商业、科学）；攻击性 → 竞技体育、政治、电子游戏。文明 = 同意那些侵犯个人自由却保护群体的规范与制裁。
- **延伸——南希·乔多罗（Nancy Chodorow, 1978, 1994）：** 女性主义精神分析社会学家——**性别化的养育模式**和早期童年发展可能导致**传统性别角色的再生产**。

### B. 镜中自我：查尔斯·库利（1909）
- 芝加哥学派；一个简单而优雅的思想：*"每个人都是一面镜子，/映照着从旁经过的他人。"* 我们互为对方的**镜子**。
- **三个步骤（Yeung and Martin 2003）：**
  1. **我们想象自己在他人眼中如何**（友善、风趣、勤奋）——尤其在意**重要他人**（父母、老板、朋友、伴侣）。
  2. **我们想象他人对我们的评价**（够聪明吗？懒吗？无聊吗？太高吗？）。
  3. **我们基于自己*以为的*评价产生对自己的感受**（胜任则自豪，不足则羞耻）。
- ⚠️ 关键点：我们回应的是我们**相信**他人做出的评价——而非他们的真实想法；我们并不总是对的，但**决定我们自我感受的是知觉，而非现实**。
- **没有社会就没有自我：** 没有相应的"他人"提供镜中映像，就没有个体的自我。我们都通过真实的或想象的关系认识自己。

### C. 心灵、自我与社会：乔治·赫伯特·米德（1934）
- 发展了库利；为**符号互动论**奠定基础（见[[Chapter 1#Symbolic Interactionism (America's contribution)|Chapter 1]]）。自我通过社会互动创造；儿童大约在**学习语言**时开始发展自我意识。
- **自我发展的三个阶段：**
  1. **预备阶段**（约3岁以下）：没有完全发展的自我意识；难以把自己与他人区分开来；在不理解含义的情况下**模仿/仿效**（做鬼脸、拍手游戏）。
  2. **游戏阶段**（约3岁以后）：**假装/扮演角色**——"妈妈"、"消防员"、"公主"、"医生" → **采择特定他人/重要他人的角色**；内化该角色的期望；也作为未来角色的**预期社会化**。
  3. **博弈阶段**（小学早期）：有规则的组织化游戏 → 必须同时考虑**所有**其他参与者的角色 → **概化他人**的视角；儿童把自己视为客体，内化群体的标准，评价自己的行为 → 开始从整体上理解社会的态度/期望。
- **自我的双重性：**
  - **"主我"（"I"）** = 主体——自发的、主动的、有创造力的、较少社会化的。
  - **"客我"（"me"）** = 客体——遵守规范的、顺从的、更社会化的、依赖他人的。
  - 二者不可分割；统一为单一自我。

### D. 拟剧论：欧文·戈夫曼（1956，《日常生活中的自我呈现》）
- 微观层面的面对面互动 = 社会其他一切方面的基石；所有意义和所有自我都**通过互动建构**。
- **W. I. 托马斯与托马斯定理：** "如果人们**把情境定义为真实的，它们在其后果中就是真实的**"（1928）。模糊的情境 → 许多可能的含义 → 我们据以行动的定义成为现实。*例子：* 一个女人扇男人耳光，可能是一场争执、一个玩笑、试图把他唤醒，或是在拍电影——每种定义都导致不同的后果（干预、报警、发笑、无视、叫救护车、要签名）。
- 我们**通过互动**定义情境——把我们的定义投射给他人：**翻白眼 + 点头**（行为表达）。
- **给予的表达**（言语的、有意的——大部分言语）vs. **流露的表达**（通常非言语、可观察、可能有意图也可能无意——面部表情、举止习惯、身体语言、衣着打扮）。我们更信任"流露的"表达，认为它更真实——但它们**同样可以被操纵**。重要的不只是你说*什么*，还有你*怎么*说。
- **印象管理：** 把社会生活当作一种**骗局游戏**——我们努力控制他人对我们的印象，动用一切沟通资源；我们说/做能传达我们自我的事，克制会损害自我的事。
- **拟剧论** —— 戏剧类比，完全是有意为之：
  - **前台** = 有助于确立意义的场景（教室 vs. 酒吧）。**区域** = 地点、布景、装饰、道具（别把啤酒带进教室）。
  - **个人前台** = 外貌、举止、"服装"，加上性别、种族、年龄。*例子：* 费里斯博士被告知她"看起来不像教授"——教授是粗犷、饱经风霜的男性长者形象，使更年轻、更友善的女性教授必须更努力地说服别人。学生在校外遇到教授（"你在这儿干嘛？"）——脱离情境，旧的剧本就不管用了。
  - **后台（后区）** = 排练/准备；**前台（前区）** = 向观众演出。我们在其中呈现不同的自我（教授今早洗澡做早餐 vs. 现在讲课）。
  - **自我是一种社会建构**（伯格与卢克曼 1966）——在互动中被创造/发明；他人也参与同意该自我的现实。
- **支持他人的自我：** "做教授"/"做学生"——我们支持他人投射的自我。**冷却"受骗者"** = 让他人保全面子（忽略教授牙缝里的菠菜叶，让小小的口误一带而过）——礼貌与得体的工具（借自骗局行话）。
- **挑战他人的自我：** 在200人的大讲堂里当众指出菠菜叶，会公开损害教授作为专家/权威的身份 → **自我呈现既关乎自我，也关乎权力**。
- **"诚实的法官"辩护：** 我们并不都在撒谎——我们必须在社会情境中呈现*某种*自我；"即使是诚实的法官，也必须扮演'诚实的法官'这个角色"（梅罗维茨 Meyrowitz 1985）。

## 4. 社会化主体

- 提供**社会化得以发生的结构化情境**的社会化力量。美国社会中最主要的四个：**家庭、学校、同伴与媒体**（还有宗教、政治与经济制度）。

### 家庭——所有社会中最重要的社会化主体
- 我们所属的**最初的群体**：早期情感/社会纽带、语言学习、规范/价值观的首次内化；我们的大部分**初级社会化**（成为成熟、负责任的社会成员）在这里发生。
- **性别角色：** 我们观察爸爸妈妈、兄弟姐妹被期望做什么（割草、叠衣服），并把这些转化为关于性别的一般规则（乔多罗 1978）。**父母的行为比他们声称相信的东西更重要**（哈尔彭与佩里-詹金斯 Halpern and Perry-Jenkins 2016）。
- **种族：** 许多黑人父母（尤其是母亲）实践**种族社会化**（特纳 Turner 2020）——教导孩子应对种族主义/歧视。
  - 低收入黑人家庭：诉诸**"体面政治"（respectability politics）**——敦促孩子避免强化负面刻板印象。
  - 中产/上层黑人家庭（道 Dow 2016）：防止儿子被看作"混混"的策略——**"经验管理"**（音乐课、棒球联盟）和**"环境管理"**（搬到以白人为主的社区）。
- 每个家庭都有自己的价值观/信念；种族、阶级、宗教、教育、政治背景都起作用；家庭随时间变化（老大与老幺的养育方式不同）；有些社会化是**无意的**（父亲的暴脾气或母亲的抑郁传递下来）。
- 家庭之所以强大，是因为年幼儿童**与外界接触有限**——"家庭就是我们的世界"。但**地点也很重要**（拉罗 Lareau 2011）：邻里/社区塑造童年的社会化——影响教育结果、社会流动，甚至健康（夏基 Sharkey 2018）。

### 学校
- 美国公立中小学建于**19世纪**；倡导者相信学校教育维系民主（尽管黑人和女性当时还没有投票权）。学校承担了越来越多的责任：体育、餐食、纪律、托管。
- 学校 = 离开家庭的第一次重要经历；通往**其他社会群体的桥梁**；儿童学会他们将在行为和学业表现上被**评判**。
- **隐性课程**（杰克逊 1968）：间接学到的行为特质——守时、整洁、守纪、勤奋、竞争、服从，以及关于阶级、种族、性别的意识形态。*例子：* 教师从学前班起就强化**异性恋常规（heteronormativity）**（甘森 Gansen 2017）。
- 教师作为榜样受到越来越多的审视（道德操守、培训、能力；戈尔茨坦 Goldstein 2014）；学校被要求承担过去由家庭/教会处理的话题——性、暴力、毒品/酒精、道德、公民教育。

### 同伴
- **同伴群体** = 年龄相仿、社会特征相似的人（同学、队友、夏令营同屋伙伴）。
- 随着年龄增长，**同伴变得比父母更重要**（影响强烈/即时），而家庭保持最长久的影响。到青春期，年轻人与同伴相处的时间比任何人都多（拉森与理查兹 Larson and Richards 1991）。同伴群体提供独立于成人控制——或反其道而行——的空间；以自身兴趣为中心的同伴亚文化（游戏、飞盘高尔夫、车库乐队）。
- **阴暗面：** 同伴群体可能成为自我怀疑、嘲笑、排斥的来源。"融入"的需要可能压倒一切——有些人背叛自己的价值观。**布拉德利与怀尔德曼（Bradley and Wildman 2002）：** 同伴压力可预测冒险行为（危险驾驶、不安全性行为、吸毒/酗酒）。**克里格与海尼（Kreager and Haynie 2011）：** 青少年饮酒受*其伴侣的朋友*的影响*比受其自己朋友的影响更大*。
- **偏见：** 青春期对态度/政治价值观的发展至关重要——同伴群体可以影响偏见水平（耶姆、埃格与丹内尔 Hjerm, Eger, and Danell 2018）。
- **好的一面：** 同伴压力可以提升学业投入/成功（麦凯布 McCabe 2016）和积极的种族认同（申、戴利与维拉 Shin, Daly, and Vera 2007）。

### 媒体
- 一个**相对新近**的主体（电视在1950年代；互联网近三十年普及），但美国成年人平均每天与媒体互动**超过11小时**（尼尔森 Nielsen 2018）。一些社会学家追问：媒体是否**篡夺了家庭的某些功能**？
- **斐济研究（A. Becker et al. 2002）：** 电视于1995年进入一个"传统上支持丰腴胃口和体型"的文化。三年内，患有**进食障碍的少女比例从12%跃升至29%**；自我催吐从0%升至11%；83%的人报告电视影响了她们对自己体型/体重的感受。
- **《十三个原因》（13 Reasons Why, Netflix）：** 对青少年自杀的露骨描绘引发"传染"担忧。**布里奇等人（Bridge et al. 2019）：** 2017年首播后的一个月里，10–17岁自杀率飙升（男孩约上升30%；九个月内超额死亡195例）。但**乌尔斯等人（Uhls et al. 2021）：** 第三季促使年轻观众与同伴/父母谈论心理健康，并寻求关于霸凌/抑郁的信息 → 媒体影响并非只有负面。
- **要点：** 我们内化许多媒体呈现的价值观/信念/规范——在信息时代，它们的影响只会增长。要问：*我们在听谁的讯息？我们被告知关于自己和彼此的什么？*

## 5. 成人社会化

- 成年人**绝非完全社会化**——生活不断呈现带有陌生规范与价值观的新情境/新角色 → **次级社会化**（贯穿生命历程的学习）。
- *例子：* 大学教导职业行为（责任心、守时），但工作会添加意料之外的期望（房产中介办公室里的"永远在成交！"）；结婚、离婚/丧偶（年长的约会者必须学习"安全性行为"、"AA制"），养育家庭、搬家、失业、退休——都需要调整态度与行为。
- **再社会化** = 用不同的规范/价值观取代先前学到的。
- **全控机构**（戈夫曼 1961）：监狱、邪教、精神病院——有时还有寄宿学校、养老院、修道院、军队。居住者**与先前的社会关系隔绝**；先前的身份被系统地剥离并重塑。*例子：* 新兵领到制服和新名字（"学员"）、剃光头——很快失去个性的痕迹，然后建立新身份：**士兵**。无论终点是善良的僧侣、受罚的罪犯还是被管理的精神病患，过程都一样。
- 重病和衰老也涉及密集的再社会化（丢弃旧行为，例如不再每天锻炼）。

### 💞 关系之窗：保利娜·奎因修女与监狱训犬
- **保利娜·奎因修女**（原名凯茜·奎因）：童年屡次离家出走被送入收容机构，后来在洛杉矶无家可归——她的生活被一只德国牧羊犬**琼妮（Joni）**扭转；这只狗是**再社会化**的开端——第一个真正的朋友，无条件的爱恢复了她的自尊；机构让她"去人格化"，被剥夺了积极的身份。
- **监狱宠物伙伴计划（Prison Pet Partnership Program, 1981）：** 奎因与利奥·巴斯塔德博士（Dr. Leo Bustad，华盛顿大学兽医学）合作，提议由女囚将收容所幼犬训练成服务犬/治疗犬，地点在华盛顿州女子惩教中心。
- **为什么有效：** 囚犯获得实质性的再社会化——新的积极身份、可在狱外运用的社交技能；训犬（通过重复和正强化实现纪律/服从）对训练者本人也是一课；狗甚至与囚犯同睡；监狱报告士气与行为改善。
- **影响：** 50%以上的州立监狱现在有类似项目；军事监狱为伤残退伍军人训练服务犬；一只服务动物训练成本可达10,000美元。与狗的每一段关系都改变了囚犯的自我感。

## 6. 地位与角色

- **地位** = 社会等级中带有整套期望的位置。正式的（"教授"、"总统"、"父母"——父母义务写进法律）或非正式的（"班级小丑"、朋友群里的"良心"）。我们**同时占据许多地位**；有些在一生中变化（婚姻/父母身份），有些不变（种族、族裔、性别）。
- **三种地位：**
  - **先赋** —— 与生俱来，不太可能改变（性别、种族）。
  - **具身** —— 位于我们的生理自我之中（美貌、残障）。
  - **自致** —— 靠努力赢得（职业、爱好、技能）或以其他方式获得（罪犯身份、精神疾病、吸毒成瘾）。
- **主地位** —— 在我们的身份中压倒其他一切的地位；它所承载的期望可能**让人看不到我们人格的其他面向**（对女性、亚洲人、医生、酒鬼的假定）→ **刻板印象**。我们每天都在使用这些期望——刻板印象有问题，但"几乎无法避免"。
- **角色** = 特定地位所期望的一整套行为；提供一份"剧本"（戈夫曼 1956；特纳 1978）。教授必须坐班答疑、请假需获批；班级小丑必须把课堂事件变成笑话，为博一笑牺牲自己的成绩。

### 多重角色与角色冲突
- 我们用个性特质描述自己（"负责任"、"照顾者"、"好胜"），它们往往映照我们的角色期望。把许多角色扮演好会增强自我感；但兼顾它们并不总那么容易。
- **角色冲突** = 两个或更多角色**期望相互矛盾**。*例子：* **参议员塔米·达克沃斯（Tammy Duckworth）**——第一位在任期内分娩的美国参议员；参议院规则禁止婴儿在表决时进入议事厅，这与她的宪法职责（以及母亲角色）相冲突。她的努力促成了一次罕见的规则修改（1977年参议院为服务犬开绿灯以来的第一次）。
- **角色紧张** = **同一角色内部**期望相互矛盾。达克沃斯作为父母必须既陪伴参与，*又*帮助养家（要求她人在华盛顿）。
- **角色退出** = 离开我们不再占据的角色。
- **新冠疫情案例：** 封锁期间的在职母亲既成为远程工作者*又*成为在家教育监督员 → 角色冲突、焦虑/压力增加（卡拉科等人 Calarco et al. 2020a）；**超过200万女性**完全退出劳动力队伍（爱德华兹 Edwards 2020）。

## 7. 情感与人格

- 情感感觉极其个人化——但它们**并非完全由社会决定，却确实是社会的**：个体的反应显示出**社会模式**。

### 🌍 全球视角：面对丧亲之痛的跨文化反应
- 所有文化都哀悼，但表达方式差异巨大：
  - **毛利人（新西兰）：** 在葬礼仪式全部完成之前死亡*并非终结*——可能长达一整**年**；哀悼结束前，死者被当作仍然活着一样与之交谈。
  - **罗姆人（Roma）：** 强烈、公开的哀悼——三天不洗澡/不刮胡子/不梳头、不进食，完全沉浸在哀悼中（有时自残）；为死者准备衣物、钱财、有用之物；哀悼者穿**白色**（与西方的黑色相对），葬礼装饰为**红色**。
  - **阿散蒂人（Ashanti，加纳）：** 红衣红土涂在手臂/额头，头带饰以红辣椒；性别化的哀悼——**女人必须哭嚎，男人必须朝天开枪**；用掉的火药 = 家族地位的标志。
  - **爱尔兰守灵（Irish wakes）：** 漫长、宾客众多的**聚会**，庆祝死者——有眼泪，也有歌唱、舞蹈、饮酒、欢笑。
- **启示：** 哀伤之类的情感是普遍的，但*如何*表达取决于社会。

### 情感的社会建构
- 互动塑造情感反应：在集会上随人群愤怒地呼喊（之后意识到自己并没有那么强烈的感受）；在教练面前忍住眼泪，赛后却哭出来。
- **角色采择情感**（同情、尴尬、羞耻）需要采纳他人的视角——你知道朋友感到痛苦，所以你感到同情。
- **情感规则**（霍克希尔德 1975）：关于恰当感受与表露的社会建构规范（"男孩不哭"、"葬礼上不许笑"）——即使不说出口，我们也感到要顺从的压力。
- **情感劳动**（霍克希尔德 1983）：把管理/出售感受作为工作要求。空乘人员无论感受如何都必须面带微笑 → 他们真实的情绪被**置换**；由于结构性压力，他们**与自己真实感受疏离**。

### 💼 职场速递：情感劳动的报酬
- **霍克希尔德的《被管理的心》（The Managed Heart, 1983）：** 空乘人员（几乎全是女性）无论受到什么对待都必须摆出愉快、镇定的面孔；航空公司推销"漂亮、活泼、百依百顺的空中小姐"，抬高了性别化/性化的期望。
- **卢万达·埃文斯（Louwanda Evans），《客舱压力》（Cabin Pressure, 2011）：** 为情感劳动添加**种族**维度。黑人飞行员（商业飞行员中不足1%）和黑人空乘（约14%）必须管理自己*和乘客*围绕种族的情感。黑人飞行员不断面对能力不足的假定（"你被假定为无能"）；一名乘客抱怨："那个黑鬼最好别开我的飞机"；一名黑人空乘被白人乘客告知"我希望你别碰我的杯子"。
- **规则：** 情感劳动者想要什么、感觉什么都不重要——工作要求微笑、顺从、隐藏真实感受。
- 服务经济 = **"感受的商品化"（commercialization of feeling）**：零售店员、前台、服务员，甚至为五星好评奔波的优步司机（斯塔克 Stark 2016）。问问自己：你的工作需要情感劳动吗？有性别化/种族化/性化的方面吗？当顾客做出你不喜欢的事时，你被期望闭嘴吗？

## 8. 在线互动

- 经典社会学视角假定互动发生在**共同在场**（面对面、物理陪伴）中——但技术越来越多地使远距离互动成为可能：视频会议、在线约会、短信、FaceTime/Zoom/Skype、远程机器人手术。
- **新冠疫情加速了这一切**（阮等人 Nguyen et al. 2020）：封锁使整个行业转向远程；孩子们通过Zoom上课；家人通过视频聊天应用（Duo、Houseparty）保持联系。
- **媒介互动社会学先驱：** 乔什·梅罗维茨（Josh Meyrowitz, 1985）、史蒂夫·琼斯（Steve Jones, 1997）、马克·史密斯与彼得·科洛克（Marc Smith & Peter Kollock, 1998）、菲利普·霍华德（Jones and Howard 2003）、巴里·韦尔曼（Barry Wellman, 2004）。
- **雪莉·特克尔（Sherry Turkle）**（MIT，技术与自我计划；1997, 2005）：在线互动让我们能够**收容并降低风险——对自我的风险**。我们控制何时/何地/如何沟通；我们可以与他人保持距离，并表演一个可能与"真实的"我们不相符的自我。结果：许多联系（朋友、粉丝、关注者）但**深度更少**；我们更不愿意冒险建立亲密纽带。在《一起孤独》（*Alone Together*, 2011）和《重拾对话》（*Reclaiming Conversation*, 2015）中，她警告：用推文/短信/快拍取代面对面对话会**使有意义的对话和共情萎缩**——呼吁放下设备，在真实的共同在场中交谈。
- **达纳·博伊德（danah boyd）——《这很复杂》（It's Complicated, 2014）：** 不那么悲观。青少年在网上寻找**私密空间**（Instagram、TikTok、Twitter），在远离成人的地方经营个人关系；他们只邀请亲密朋友。**与成人的对比：** 成年人发推/发帖是为了*扩大*圈子、广播成就；青少年只为少数选定的人这样做。
- **后现代观点（霍尔斯坦与古布里厄姆 Holstein and Gubrium 2000；戈特沙尔克 Gottschalk 1993）：** 技术是后现代生活的主要特征——需要新的自我发展解释。
- **肯尼斯·格尔根（Kenneth Gergen, 1991）——饱和自我：** 后现代个体发展出**"拼贴人格"**，"从任何可得的来源借用身份的零零碎碎"（第150页）——自我由多重影响建构，真实的与虚拟的，这是早期符号互动论者未曾预见的。

> **问题：** 随着我们越来越多地与数字技术互动、并通过数字技术互动，我们将变成什么样的人？

## 9. 结语——我们是社会化的囚徒吗？

- 社会化可能是**同质化的、保守的**——把人们推向最低公分母、推向主流。**但**从来没有两个人真正一样。
- 我们**不是被动的接受者**——我们是主动的参与者，拥有**能动性**（自发性、智慧、创造力；自由意志）。符号互动论：我们总是在解释、定义、理解并对我们的社会环境做出回应的过程中工作。
- 这个过程是**互惠的、多向的**——**你在塑造社会，正如社会在塑造你。**

## 快速记忆要点
- **社会化 = 双向：** 社会*教导* + 我们*内化*——"学习所在社会的生活方式并使之成为自己的"。
- **天性 vs. 教养 = 两者都对**——遗传给出*潜能*；社会环境决定我们是否*实现*它。（睾酮：引起竞争，也由竞争引起。）
- **隔离证明社会化：** 奈特（"没有人为之表演，我变得无关紧要"）、吉妮、特平家的孩子们——**没有接触，就没有自我。**
- **弗洛伊德 = 心灵的三角形：** **本我**（快乐）、**自我**（现实调解者）、**超我**（良心 + 自我理想）。固着 → 成年心结。
- **库利三步：** 想象自己看起来如何 → 想象他人的评价 → 基于*所感知的*评价产生对自己的感受。关键是*我们以为*他们怎么想！
- **米德的阶段：** **预备**（模仿）→ **游戏**（特定/重要他人）→ **博弈**（概化他人）。"主我" = 主体/自发；"客我" = 客体/顺从。
- **托马斯定理：** "如果人们把情境定义为真实的，它们在其后果中就是真实的。"
- **戈夫曼 = 戏剧：** 前台/区域/个人前台，后台 vs. 前台，**印象管理**，**冷却"受骗者"**（保全面子）。"即使是诚实的法官，也必须扮演'诚实的法官'这个角色。"
- **给予的表达 = 言语/有意；流露的表达 = 非言语/可能无意**（但两者都可以被操纵）。
- **社会化主体（家学同媒 FSPM）：** **家**庭（最重要）→ **学**校（隐性课程）→ **同**伴（青春期最强烈）→ **媒**体（每天11+小时；斐济研究）。
- **再社会化 / 全控机构：** 剥离旧身份 → 建立新身份（新兵领制服、新名字、剃光头）。
- **地位：** **先赋**（与生俱来）/ **具身**（生理）/ **自致**（赢得的）；**主地位**压倒其他一切（→ 刻板印象）。
- **角色冲突 = 角色之间；角色紧张 = 角色内部**（达克沃斯 = 两者兼具；新冠妈妈们 = 冲突 → 200万角色退出）。
- **情感是社会性的：** 丧亲之痛处处不同（毛利人一整年、罗姆人穿白衣、阿散蒂人开枪、爱尔兰守灵）；**情感规则**支配表露；**情感劳动** = 在工作中出售你的感受（空乘人员）。
- **在线：** **共同在场** vs. 媒介互动；特克尔 = 失去深度；博伊德 = 青少年想要私密空间；格尔根 = **饱和自我 / 拼贴人格**。
- **能动性：** 你不是囚徒——"你在塑造社会，正如社会在塑造你。"

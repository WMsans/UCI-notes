# 关于谁在玩独立游戏

> 参考视频：<https://www.youtube.com/watch?v=wnKI3BsSmUE>

## 结论

1. 重视"游戏作为放松活动"和"自由探索"
2. 更追求**创新**性、**独特**性、自我表达，而不是画面质量、热门 IP 与社交属性
3. 认为独立游戏"独特、**实验性**、充满热情"

## 理想独立游戏体验

1. 重视**深度世界观**：非线性叙事、原创 IP、深度世界观
2. 重视**创新**：玩家赞赏开发者尝试新机制或叙事方式（即使不完美）
3. 重视**风格化美术**（如手绘 2D 或鲜艳 3D）
4. 重视**音乐**：**独特**并**差异化**
5. 重视**单机**：若有多人模式，在线合作最受欢迎
6. 重视**慢节奏**、**策略性**
7. 重视**小而精**：较短流程（2–100 小时），但期望"质量 > 数量"

## 购买行为与习惯

1. **买断制**
2. 厌恶**广告** / **平衡性调整** / **卖数值**
3. 不会全价购买：冲冬促 / 史低
4. 价格敏感区间：**15–25 美元**（低于 15 可能引发质量疑虑，高于 25 需对标 AAA 内容量）
5. 购买决策路径：
   - 发现：YouTube、Steam 促销、亲友推荐
   - **决策**：实机演示、截图、官方预告片
   - 转化：实机演示质量、折扣活动、评分

## 总结

1. 突出**差异化创新**
2. 艺术风格与音乐是低成本提升体验的关键
3. 长尾效应显著：首发后持续更新 + 促销
4. 优先展示**实机**玩法视频
5. 重视玩家社区与口碑

# 银河恶魔城设计 Tips：一般方法论

1. 确定角色的能力
   - 分清**核心能力**和**关卡能力**
2. 先设计框架，再设计细节
3. 使用工具：
   - 先 Google Drawing 和你的图论知识，设计最笼统的框架
   - 然后用引擎 / Excel 描述更细节（和科学的）设计，包括技能获取、重要剧情、以及地图联系等
   - 如果觉得困难，可以先设计一条主线，再在主线上添加探索内容和错综道路
4. 尽量避免直线
5. 在死路的设计上
   - 一定要让死路尽可能**早**出现（避免玩家走了一分钟发现要原路返回）
   - 这些死路在习得一些能力后会变成近路
   - 若真的只是死路，必须放置奖励
6. 区域的重复利用
   - 游戏通常由很多区域组成，每个区域都有自己的主题
   - 每个场景的流程为 **15–20 分钟**为最佳
   - 为了节省成本，可以重复利用区域：将区域分成 3–4 个部分，在游戏后期就能走这路的另一些部分。分部分的方法可以用一些早期无法通过的路等
   - 尽管如此，也要保证在**美术、难度、音乐**上的改变，避免枯燥
